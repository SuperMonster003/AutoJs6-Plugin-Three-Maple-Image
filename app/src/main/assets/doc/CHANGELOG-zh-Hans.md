# 版本记录

## v1.2.1

###### 2026/09/19

* `修复` AGP 9.1 构建时的 SDK XML v4 解析警告, 以及 JVM 单元测试误触发 APK 原生库对齐检查的问题 (共享构建插件 1.8.3)
* `优化` compileSdk/targetSdk 升级至 37 (Android 17)

## v1.2.0

###### 2026/09/13

* `新增` 发行历史页面, 支持多语言显示及英文回退
* `优化` 完善发行签名, APK 变体及生成文档一致性校验

## v1.1.0

###### 2026/09/12

* `新增` 编辑器支持撤销/重做及撤销恢复原图操作, 增加裁剪比例预设和 -45° 至 +45° 微调旋转 (保持输出尺寸)
* `新增` 扩展画笔, 荧光笔, 马赛克与橡皮擦工具, 并支持可拖动的多行文字, 描边, 阴影与旋转
* `新增` 编辑器支持跟随源格式或另存为 JPEG/PNG/WebP, 可调整有损压缩质量 (无损 WebP 需要 Android 11+)
* `新增` 转换器无损 WebP, 最多 256 色图像的索引 PNG, JPEG / 有损 WebP 目标文件大小, 以及不放大图像的长边缩放模式
* `新增` 可选的安全 EXIF 保留, 同时始终移除 GPS, 内嵌预览与不透明元数据, 并将方向归一化
* `修复` 仅探测图像尺寸时未返回位图而导致有效图像被拒绝的问题
* `修复` 深色模式下编辑器工具标签难以阅读的问题
* `优化` 完善配置变更后的状态恢复, 内存及输出限制检查
* `优化` 统一 10 种语言的 README 与插件说明, 并补充功能截图
* `优化` 构建阶段阻止意外引入原生依赖, 并输出 JSON 校验报告

## v1.0.1

###### 2026/08/08

* `修复` 在 AutoJs6 插件中心启用插件时因服务返回空绑定 (onNullBinding) 导致无法启用的问题
* `优化` 精简插件名称与描述, 统一各语言用户文档的表述

## v1.0.0

###### 2026/08/02

* `新增` AutoJs6 文件管理器的图像文件增加 "编辑图像" 及 "转换图像" 菜单, 结果保存为同目录新文件, 原图保持只读
* `新增` 编辑器支持裁剪, 旋转, 翻转, 亮度, 对比度, 饱和度, 色温, 画笔, 文字与最多 8 步撤销, 并自动应用 EXIF 方向
* `新增` 转换器支持 JPEG / PNG / WebP 输出: 质量 1-100 可调, 尺寸提供原始 / 百分比 / 自定义三种模式, 支持宽高比锁定, JPEG 背景色选择与输出大小实时预估
* `新增` 识别 bmp / gif / heic / heif / jpg / jpeg / png / webp 扩展名及全部 `image/*` MIME 类型
* `新增` 基于 explorer-action 协议 v3 注册插件服务: 一次性只读输入配合宿主拥有的输出事务, 不申请存储或网络权限
* `新增` 插件信息, 界面, 使用说明, README 与更新日志支持简体中文, 繁体中文 (香港 / 台湾), 英语, 法语, 西班牙语, 日语, 韩语, 俄语与阿拉伯语共 10 种语言
* `优化` 屏幕旋转等配置变更期间保留编辑器与转换器会话, 包括画布工具, 对话框草稿, 转换选项, 撤销历史与执行中的任务
* `优化` 以一次性事务声明, 动作忙碌保护与可取消协程守护输出写入, 避免重复提交与残留半成品文件
* `优化` 强化输出 MIME 类型校验, 位图内存回收与多语言资源一致性
* `依赖` 附加 AndroidX ExifInterface 版本 1.4.2, 用于图像方向解析
* `依赖` 附加 Robolectric 版本 4.16.1 (仅用于单元测试)
