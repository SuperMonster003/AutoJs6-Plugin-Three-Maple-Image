# История выпусков

## v1.2.0

###### 2026/09/13

* `Функция` Локальная история выпусков в интерфейсе с переводами и английским запасным вариантом
* `Улучшение` Проверка полной настройки подписи, ожидаемого набора APK и воспроизводимости документации

## v1.1.0

###### 2026/09/12

* `Функция` Добавлены симметричные отмена / повтор, обратимое восстановление оригинала, предустановки соотношения сторон обрезки и точный поворот от -45° до +45° без изменения выходных размеров
* `Функция` Рисование дополнено Пером, Маркером, Мозаикой и Ластиком, а текст - перетаскиваемыми многострочными блоками с обводкой, тенью и поворотом
* `Функция` В редактор добавлены сохранение в исходный формат / JPEG / PNG / WebP, регулируемое качество с потерями и WebP без потерь на Android 11+
* `Функция` В конвертер добавлены WebP без потерь, индексированный PNG для изображений до 256 цветов, целевой размер файла для JPEG / WebP с потерями и изменение размера по длинной стороне без увеличения
* `Функция` Добавлено необязательное сохранение безопасных EXIF с обязательным удалением GPS, встроенных эскизов и непрозрачных метаданных и нормализацией ориентации
* `Исправление` Исправлено отклонение корректных изображений, когда проверка только границ BitmapFactory правильно не возвращала bitmap
* `Исправление` Исправлены нечитаемые подписи инструментов редактора в тёмном режиме
* `Улучшение` Расширены восстановление состояния, контроль ограничений памяти / вывода и регрессионное покрытие до 23 наборов / 99 тестов
* `Улучшение` README и инструкции хоста на 10 языках обновлены из общих источников; добавлены три снимка реального устройства без персональных данных
* `Улучшение` Проверка сборки отклоняет непреднамеренные нативные зависимости и создает отчет JSON

## v1.0.1

###### 2026/08/08

* `Исправление` Плагин не включался из центра плагинов AutoJs6, потому что служба возвращала пустую привязку (onNullBinding)
* `Улучшение` Сокращены название и описание плагина, унифицированы формулировки пользовательской документации на всех языках

## v1.0.0

###### 2026/08/02

* `Функция` Первый выпуск Image Tools: два действия дополнительного меню, `Редактировать изображение` и `Преобразовать изображение`, для одного изображения в файловом менеджере AutoJs6; результат сохраняется как новый файл рядом с исходным, а исходный остается только для чтения
* `Функция` Редактор с обрезкой, поворотом, отражением, яркостью, контрастностью, насыщенностью, цветовой температурой, кистью, текстом и отменой до 8 шагов, с автоматическим применением ориентации EXIF
* `Функция` Конвертер с выводом JPEG / PNG / WebP: качество 1-100, три режима размера (Исходный / Процент / Пользовательский), фиксация соотношения сторон, выбор цвета фона JPEG и оценка размера вывода в реальном времени
* `Функция` Распознавание расширений bmp / gif / heic / heif / jpg / jpeg / png / webp и всех MIME-типов `image/*`
* `Функция` Служба плагина зарегистрирована на протоколе explorer-action v3: одноразовый вход только для чтения в паре с принадлежащими хосту транзакциями вывода, без запроса разрешений на хранилище и сеть
* `Функция` Сведения о плагине, интерфейс, инструкции, README и журнал изменений на 10 языках: упрощенный китайский, традиционный китайский (Гонконг / Тайвань), английский, французский, испанский, японский, корейский, русский и арабский
* `Улучшение` Сессии редактора и конвертера сохраняются при изменениях конфигурации, таких как поворот экрана, включая инструменты холста, черновики диалогов, параметры преобразования, историю отмены и выполняющиеся задачи
* `Улучшение` Запись вывода защищена одноразовыми объявлениями транзакций, защитой от одновременных действий и корутинами, безопасными при отмене, что исключает повторные отправки и остатки незавершенных файлов
* `Улучшение` Усилены проверка MIME-типа вывода, освобождение памяти растровых изображений и согласованность многоязычных ресурсов
* `Зависимость` Добавлен AndroidX ExifInterface 1.4.2 для безопасного чтения метаданных ориентации изображений
* `Зависимость` Добавлен Robolectric 4.16.1 для модульных тестов жизненного цикла и транзакций вывода
