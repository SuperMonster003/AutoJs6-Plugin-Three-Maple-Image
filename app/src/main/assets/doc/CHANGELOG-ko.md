* `수정` 앨범에서 이미지를 연 뒤 좌우로 넘기면 옆 이미지가 계속 로드 중으로 표시되고 인쇄도 계속 사용할 수 없는 경우가 있었음

## v3.1.0

###### 2026/10/14

* `힌트` 삭제한 이미지는 먼저 휴지통으로 이동합니다: Android 11 이상은 시스템 휴지통 (다른 갤러리 앱에서도 보임) 으로, 약 30일 후 시스템이 비웁니다. Android 7-10은 이 앱의 휴지통으로, 30일 동안 보관하고 남은 공간의 최대 10분의 1 (최대 2 GiB) 까지 사용하며, 앱을 삭제하면 함께 지워집니다. 설정 > 휴지통에서 끌 수 있으며, 끄면 삭제 전에 확인하고 되돌릴 수 없습니다
* `힌트` Android 11 이상에서는 다른 앱이 저장한 이미지를 삭제, 이동, 이름 변경할 때마다 시스템이 작업 묶음별로 한 번 확인합니다. 설정 > 저장소 권한에서 미디어 관리 (Android 12 이상) 를 켜면 확인하지 않습니다
* `기능` 이미지 그리드에서 여러 장을 선택할 수 있습니다: 이미지를 길게 눌러 시작하고, 탭하여 추가 또는 해제하며, 길게 누른 뒤 손을 떼지 않고 끌면 범위를 선택합니다 (위나 아래 가장자리에서는 자동 스크롤). 모두 선택과 선택 반전도 지원합니다. 여러 장을 한 번에 공유, 즐겨찾기, 이동, 복사, 삭제하거나 한 장의 이름을 바꾸고 상세 정보를 볼 수 있습니다
* `기능` 삭제는 하단 막대에서 실행 취소할 수 있습니다. 홈 메뉴에 휴지통이 추가되어 이미지별 남은 일수를 보여 주고, 복원, 영구 삭제, 비우기를 할 수 있습니다
* `기능` 이동과 복사는 앨범을 고르거나 Pictures에 새 앨범을 만들 수 있으며, 최근 사용한 앨범이 앞에 표시됩니다. 대상에 같은 이름의 이미지가 있으면 한 번만 묻습니다: 둘 다 유지 (새 이름에 번호 추가), 건너뛰기, 바꾸기 (기존 이미지는 휴지통으로). 여러 장일 때는 진행 상황을 보여 주고 취소할 수 있으며, 이동과 이름 변경은 실행 취소할 수 있습니다
* `기능` 즐겨찾기: 즐겨찾기한 이미지는 앨범 목록 맨 앞의 즐겨찾기 앨범에 모입니다. Android 11 이상에서는 설정의 시스템 즐겨찾기 동기화로 다른 갤러리 앱에서도 보이게 할 수 있습니다
* `기능` 앨범에서 연 뷰어에는 상단 막대에 하트 버튼이 추가되고, 하단 막대의 삭제가 다른 앱으로 열기를 대신합니다. 다른 앱으로 열기, 이름 변경, 이동, 복사는 오른쪽 위 메뉴에 있습니다
* `기능` 권한을 부여한 폴더의 이미지를 삭제 (확인 후 휴지통 없이 영구 삭제) 하고 이름을 바꿀 수 있습니다
* `의존성` 즐겨찾기와 Android 7-10 휴지통 기록을 저장하기 위해 Room 2.8.1 추가

* `기능` 설정에 저장공간 권한 페이지 추가: 현재 접근 상태 확인, 다시 허용, Android 14 이상에서 선택한 사진 관리, 승인한 폴더 추가 및 제거 (사진 접근이 없어도 앨범으로 표시), 선택 사항인 모든 파일 접근
* `기능` AutoJs6 파일 관리자의 폴더 메뉴에 앨범으로 보기 추가. 폴더의 이미지를 그리드로 보여 주고 하위 폴더로 들어갈 수 있음
* `의존성` 홈 화면과 앨범 페이지 간 이동을 위해 Navigation Compose 2.10.2 추가
