# AutoJs6 3-Maple Image

Image Viewer와 Image Tools를 3-Maple Image로 통합하여 이미지 보기, 편집 및 형식 변환 제공.
공통 설정 화면에서 언어, 야간 모드, 테마 색상 및 네 가지 런처 아이콘 선택 가능.
앱 ID가 io.github.supermonster003.autojs6.plugin.imageviewer / io.github.supermonster003.autojs6.plugin.imagetools에서 io.github.supermonster003.autojs6.plugin.three.maple.image(으)로 변경됩니다. Android는 별도 앱으로 설치하며 기존 앱과 데이터를 유지할 수 있고 설정은 자동으로 이전되지 않습니다.


3-Maple Image는 파일 관리자에서 AVIF, BMP, GIF, HEIC, HEIF, JFIF, JPE, JPEG, JPG, PNG 및 WEBP 파일의 기본 이미지 작업을 제공합니다.

HEIC와 HEIF에는 Android 9 이상이 필요하고 AVIF에는 Android 12 이상이 필요합니다. 플랫폼 디코더를 사용할 수 없으면 뷰어는 조용히 실패하는 대신 정확한 요구 사항을 표시합니다.

초대형 JPEG, PNG 및 정적 HEIC/HEIF는 제한된 저해상도 미리보기를 사용하고 확대 중에는 현재 보이는 고해상도 영역만 디코딩합니다. 타일 캐시는 페이지 전환이나 메모리 압박 시 즉시 해제됩니다.

명시적으로 선택한 그룹만 열려면 AutoJs6에서 다중 선택 모드로 들어가 같은 폴더의 지원 이미지 1개에서 128개를 선택한 뒤 `이미지 보기`를 탭합니다. 뷰어는 선택 순서를 유지하고 좌우 넘기기를 이 그룹 안으로 제한합니다. 선택한 각 URI는 별도로 검증되며 항상 읽기 전용입니다. 선택한 각 이미지는 하단 바의 `삭제`로 AutoJs6 휴지통으로 옮길 수 있으며 실행 취소할 수 있습니다. 파일 하나를 탭해 연 이미지도 같은 방법으로 삭제할 수 있지만, 같은 폴더의 다른 이미지는 삭제할 수 없습니다.

뷰어는 이미지를 화면에 맞추고 1배에서 같은 폴더 좌우 넘기기, 초점 핀치 확대, 이동, 두 번 탭하여 화면 맞춤과 탭한 지점 중심의 2.5배 확대 전환, 페이지별 메타데이터를 지원합니다. 핀치 중과 두 번 탭한 뒤에는 현재 배율이 잠시 표시됩니다. GIF 애니메이션은 반복 재생되며 일시중지/계속 컨트롤이 표시되고, 정적 이미지에서는 숨겨집니다. 이미지는 반투명 오버레이 막대 아래까지 화면 전체를 채웁니다. 이미지를 탭하여 막대를 숨기거나 표시하고, 여러 이미지를 열었을 때는 제목 표시줄에 `3 / 12` 형식의 페이지 번호가 표시됩니다. 공유 및 다른 앱으로 열기는 처음 연 이미지에서 사용할 수 있고, 세션으로만 연 이웃 페이지에서는 비활성화됩니다. 두 번 탭 확대 배율과 최대 확대 배율, 한 손가락 확대/축소, 가장자리를 탭하여 넘기기, 아래로 스와이프하여 닫기 등은 3-Maple Image의 `설정` > `뷰어`에서 조정할 수 있습니다.

`회전`은 현재 보기만 회전하고 활성 확대를 유지합니다. 오른쪽 위 메뉴의 `확대 재설정`은 원래 방향과 화면 맞춤을 함께 복원합니다.

`상세 정보`를 사용하면 하단 시트가 열리며 파일 이름, MIME 유형, 크기, 해상도와 가능한 EXIF 촬영 시각, 기기, 노출 및 방향을 확인할 수 있습니다. GPS 메타데이터가 있으면 기본적으로 존재 여부만 알립니다. `설정` > `뷰어` > `위치 정보 표시`를 켜면 촬영 장소의 좌표 (십진수와 도분초)를 표시하고 `지도에서 열기`도 제공합니다.

정보 바에는 MIME 유형, 파일 크기, 디코딩된 해상도가 항상 표시됩니다. Android 8.0 이상에서 디코더가 제공하는 경우 디코딩 픽셀 심도 (bpp)와 출력 색 공간도 표시됩니다.

사진은 EXIF 방향에 따라 자동으로 회전하거나 반전됩니다. `회전`은 보정된 표시에 보기 전용 회전을 추가합니다.

오른쪽 위 메뉴의 `인쇄 / PDF로 저장`은 EXIF 보정과 수동 보기 회전을 유지한 현재 이미지 전체를 Android 시스템 인쇄 화면으로 보냅니다. 애니메이션 GIF는 탭할 때 보이는 프레임을 사용합니다. 확대와 이동은 출력을 자르지 않으며 플러그인은 임시 이미지나 PDF 파일을 만들지 않습니다.

파일 관리자의 디렉터리 메뉴에서 `앨범으로 보기`를 선택하면 호스트 세션을 통해 해당 디렉터리를 앨범으로 엽니다. 최대 8단계의 하위 폴더가 폴더 셀로 표시되고, 이미지는 뷰어에서 열려 그 폴더 안에서 좌우로 넘길 수 있으며, 폴더마다 처음 4096개 항목만 나열합니다. 이 모드는 저장소 권한이 필요 없고 파일 경로를 공개하지 않으며, 관리 작업은 제공되지 않습니다.

파일 메뉴의 `이미지 편집`과 `이미지 변환`은 기본적으로 원본 옆에 새 파일을 만듭니다. 저장 대화상자나 변환 화면에서 `원본에 덮어쓰기`를 켜면 원본을 대체하며 (형식 유지) 8초 안에 실행 취소할 수 있습니다. 모든 출력은 임시로 저장하고 다시 읽어 확인한 뒤 게시하므로 실패해도 쓰다 만 파일이 남지 않습니다.

호스트 빌드 5352 이상이 필요합니다.

AutoJs6 스크립트도 `gallery` 객체로 3-Maple Image 를 사용할 수 있습니다. `gallery.pick` 은 이미지 선택 화면을 열어 고른 이미지를 돌려주고, `gallery.view` 는 뷰어로 이미지를 보여 주며, `gallery.edit` 는 편집기를 열고 AutoJs6 가 결과를 저장하고, `gallery.convert` 는 화면 없이 이미지를 변환합니다. 이미지는 AutoJs6 가 열고 결과도 AutoJs6 가 기록하므로 스크립트는 자신이 접근할 수 있는 파일만 다룹니다. 이미지 선택에는 플러그인의 사진 접근 권한이 필요하며 선택 화면이 먼저 요청합니다. 이 기능에는 AutoJs6 6.8.0 호스트 빌드 5439 이상이 필요합니다.

안전 및 개인정보 제한:

- 선택한 원본은 임시 읽기 전용 `content` URI를 사용하고, 바로 이웃한 파일은 범위가 제한된 호스트 `readSiblings` 세션으로만 엽니다.
- 8 TiB보다 큰 파일은 거부됩니다.
- AutoJs6에서 열 때 플러그인은 권한을 요청하지 않으며, 네트워크 권한도 선언하지 않습니다.
- 삭제는 선택한 파일만 AutoJs6 휴지통으로 옮깁니다. 이동, 이름 바꾸기와 파일 정보는 호스트 기능으로 유지됩니다.
