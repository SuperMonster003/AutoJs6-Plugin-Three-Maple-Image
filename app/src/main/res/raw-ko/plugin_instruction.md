3-Maple Image는 이미지를 보고 편집하며 이미지 형식을 변환하는 플러그인입니다. 단독으로 열어 기기의 이미지를 앨범별로 탐색하고 정리할 수 있으며, AutoJs6 파일 탐색기에서 이미지 파일을 탭해도 3-Maple Image로 표시되고 파일 메뉴에서 편집과 변환도 할 수 있습니다. AutoJs6 스크립트는 `gallery` 모듈을 통해 이 플러그인을 호출할 수 있습니다.

### 시작하기

1. 3-Maple Image를 열고 안내에 따라 사진 접근을 허용하면 홈 화면에 기기의 이미지가 앨범별로 표시됩니다. 허용하지 않으면 "이미지 선택" 또는 "폴더 선택"으로 시스템 선택기에서 이미지를 열 수 있습니다.
2. AutoJs6의 "플러그인 센터"에서 3-Maple Image를 활성화합니다. 이후 AutoJs6 파일 탐색기에서 이미지 파일을 탭하면 볼 수 있고, 파일 메뉴의 "이미지 편집"과 "이미지 변환"으로 편집과 변환을 할 수 있습니다.

### 주요 기능

- **앨범**: 홈 화면에 이미지를 앨범별로 표시하며 "즐겨찾기" 앨범이 맨 앞에 옵니다. 앨범 이름과 파일 이름을 검색하고 정렬, 열 수, 날짜별 그룹을 조정할 수 있으며, 앨범을 길게 누르면 "고정", "제외", "숨기기"를 할 수 있습니다.
- **뷰어**: 확대 및 축소, 페이지 넘기기, 미리보기 막대, "회전"을 지원하며 GIF 애니메이션은 반복 재생됩니다. 오른쪽 위 메뉴에서 "슬라이드쇼", "배경화면으로 설정", "사본 공유", "인쇄 / PDF로 저장" 등을 사용할 수 있습니다.
- **상세 정보**: "상세 정보"를 탭하면 파일 이름, 크기, 해상도, EXIF 촬영 정보를 볼 수 있습니다.
- **정리**: 이미지 그리드에서 길게 누르면 다중 선택이 시작되어 공유, 즐겨찾기, 이동, 복사, 삭제를 할 수 있습니다. 삭제한 이미지는 먼저 "휴지통"으로 이동하며 알림 메시지에서 실행 취소할 수 있습니다.
- **편집**: 편집기 도구는 "변형", "조정", "필터", "텍스트" 등 여섯 그룹으로 나뉘며 실행 취소와 다시 실행을 지원합니다. 편집과 변환은 기본적으로 새 파일로 저장하며 원본은 바뀌지 않습니다. "원본에 덮어쓰기"를 켠 경우에만 원본을 대체하며, 대체는 실행 취소할 수 있습니다.
- **변환**: "이미지 변환"으로 형식 (JPEG, PNG, WebP), 품질, 크기를 바꾸고 출력 크기를 미리 볼 수 있습니다. 앨범이나 AutoJs6 파일 탐색기에서 여러 이미지를 선택하면 일괄 변환할 수 있습니다.

### 스크립트에서 사용하기

AutoJs6 스크립트에서는 `gallery` 모듈을 통해 이 플러그인을 호출합니다. 다음 예제는 사용자가 최대 5장의 이미지를 선택하게 한 뒤 긴 변 1080픽셀의 WebP로 변환하고 뷰어로 결과를 보여 줍니다:

```js
let images = gallery.pick({ multiple: true, maxCount: 5 });
if (images) {
    let outputs = images.map((image) => gallery.convert(image.path, { format: 'webp', longEdge: 1080 }).path);
    gallery.view(outputs);
}
```

- 모든 메서드에는 Promise를 반환하는 비동기 형태가 있습니다 (예: `gallery.pickAsync`). 동기 방식의 `pick`, `edit`, `convert`는 오래 기다릴 수 있으므로 UI 스레드에서 호출할 수 없습니다.
- 이미지는 파일 경로로 지정하며 상대 경로는 스크립트의 작업 디렉터리를 기준으로 해석됩니다. 출력은 기본적으로 원본 옆에 기록되며 (파일 이름에 `_converted` 또는 `_edited`가 붙음), `output` 옵션으로 위치를 지정할 수도 있습니다.
- 이미지 선택에는 플러그인의 사진 접근 권한이 필요하며 선택 화면이 먼저 요청합니다. 선택, 보기, 편집은 플러그인 화면을 열므로 AutoJs6 화면이 보이는 상태에서 스크립트를 실행하는 것이 더 안정적입니다.
- 실행 전에 `gallery.isAvailable()`로 플러그인을 사용할 수 있는지 확인할 수 있습니다. 전체 옵션과 오류 코드는 [AutoJs6 문서 > gallery](https://docs.autojs6.com/#/gallery)를 참고하세요.

### 요구 사항

- Android 7.0 이상. HEIC 및 HEIF 이미지는 Android 9 이상, AVIF 이미지는 Android 12 이상이 필요합니다.
- AutoJs6에서 사용하려면 (파일 탐색기와 `gallery` 모듈) AutoJs6 6.8.0 이상이 필요하며 "플러그인 센터"에서 이 플러그인을 활성화해야 합니다. 단독으로 사용할 때는 AutoJs6가 필요하지 않습니다.
- 사진 접근 권한은 홈 화면에서 앨범별로 이미지를 탐색하고 스크립트가 이미지를 선택하는 데 사용됩니다. AutoJs6 파일 탐색기나 다른 앱에서 이미지를 열 때는 권한을 요청하지 않습니다.
- "모든 파일 접근"과 "미디어 관리"는 선택 권한으로, 앨범 숨기기와 이미지를 삭제하거나 이동할 때마다 확인하는 과정을 생략하는 데 사용됩니다. "설정" > "저장공간 권한"에서 켤 수 있습니다.

### 자주 묻는 질문

**사진 접근 권한을 허용하지 않았을 때의 사용 방법**

홈 화면에 "이미지 선택"과 "폴더 선택"이 표시되며 시스템 선택기를 통해 이미지를 보고 편집하고 변환할 수 있습니다. 나중에 "설정" > "저장공간 권한"에서 다시 허용할 수 있으며, Android 14 이상에서 일부 사진만 허용한 경우 홈 화면에는 해당 사진만 표시되고 "선택한 사진 관리"로 추가하거나 뺄 수 있습니다.

**파일 메뉴에 "이미지 편집"과 "이미지 변환"이 없을 때의 조치**

AutoJs6 6.8.1 이상에서는 이 두 항목이 파일 메뉴의 3-Maple Image 하위 메뉴에 있습니다. 그래도 찾을 수 없으면 "플러그인 센터"에서 플러그인이 활성화되어 있는지, 파일이 지원되는 이미지 형식인지 확인하고 AutoJs6를 최신 버전으로 업데이트하세요.

**삭제한 이미지 복원**

앨범에서 삭제한 이미지는 먼저 홈 화면 오른쪽 위 메뉴의 "휴지통"으로 이동하며 여기서 복원할 수 있고, 약 30일 후 자동으로 삭제됩니다. AutoJs6에서 열어 삭제한 이미지는 AutoJs6 휴지통으로 이동하며 AutoJs6에서 복원합니다.

**사진 위치 정보의 표시와 유지**

좌표는 기본적으로 표시되지 않으며 편집, 변환, "사본 공유"로 만든 이미지에서도 위치 정보가 제거됩니다. "설정"에서 "위치 정보 표시"를 켜면 상세 정보에 좌표가 표시되고 "지도에서 열기"를 사용할 수 있으며, 저장하거나 변환할 때 "위치 정보 유지"를 선택할 수 있습니다. 이 플러그인에는 네트워크 권한이 없습니다.

전체 기능 설명, 지원 형식, 자주 묻는 질문은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Maple-Image)를 참고하세요.
