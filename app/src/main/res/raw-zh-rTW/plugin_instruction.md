# 影像工具

Image Tools 為 AutoJs6 Explorer 提供 `編輯影像` 和 `轉換影像` 兩個 overflow 動作.

編輯器支援裁切, 旋轉, 水平和垂直翻轉, 亮度, 對比, 飽和度, 色溫, 畫筆, 文字和復原. 轉換器支援 JPEG, PNG 和 WebP 輸出, 品質控制, 百分比或自訂縮放, 比例鎖定及 JPEG 背景選擇.

外掛需要 AutoJs6 建置版本 5269 或更高版本. 外掛完全使用 JVM 實作, 與裝置 ABI 無關.

安全和隱私限制:

- 僅透過精確的唯讀 `content` URI 存取開啟來源檔案.
- 僅向主程式擁有的精確輸出交易 URI 編碼.
- 外掛不會在來源檔案旁寫入, 也不會回傳任意 URI.
- 編碼輸出僅限 JPEG, PNG 或 WebP, 且最大為 256 MiB.
- 外掛不要求儲存或網路權限.
