3-Maple Image は画像の表示, 編集と画像形式の変換を行うプラグインです. 単独で開いて端末上の画像をアルバムごとに閲覧, 整理できます. AutoJs6 のファイルエクスプローラーで画像ファイルをタップしたときも 3-Maple Image で表示され, ファイルメニューから編集と変換も行えます. AutoJs6 スクリプトは `gallery` モジュールを通じて本プラグインを呼び出せます.

### はじめに

1. 3-Maple Image を開き, 案内に従って写真へのアクセスを許可すると, ホームに端末上の画像がアルバムごとに表示されます. 許可しない場合は "画像を選択" または "フォルダーを選択" からシステムの選択画面で画像を開けます.
2. AutoJs6 の "プラグインセンター" で 3-Maple Image を有効にします. その後は AutoJs6 のファイルエクスプローラーで画像ファイルをタップすると表示でき, ファイルメニューの "画像を編集" と "画像を変換" で編集と変換を行えます.

### 主な機能

- **アルバム**: ホームに画像をアルバムごとに表示し, "お気に入り" アルバムを先頭に置きます. アルバム名とファイル名の検索, 並べ替え, 列数, 日付ごとのグループ化を調整でき, アルバムを長押しすると "固定", "除外", "非表示" を選べます.
- **ビューアー**: 拡大縮小, ページ送り, サムネイル列, "回転" に対応し, GIF アニメーションはループ再生します. 右上のメニューには "スライドショー", "壁紙に設定", "コピーを共有", "印刷 / PDF に保存" などがあります.
- **詳細**: "詳細" をタップすると, ファイル名, サイズ, 解像度と EXIF の撮影情報を確認できます.
- **整理**: 画像グリッドで長押しすると複数選択になり, 共有, お気に入り, 移動, コピー, 削除ができます. 削除した画像はまず "ゴミ箱" に入り, メッセージから取り消せます.
- **編集**: エディターのツールは "変形", "調整", "フィルター", "テキスト" など 6 つのグループに分かれ, 元に戻すとやり直しに対応します. 編集と変換は既定で新しいファイルとして保存し, 元の画像は変わりません. "元の画像に上書き" をオンにしたときだけ元の画像を置き換え, 置き換えは取り消せます.
- **変換**: "画像を変換" で形式 (JPEG, PNG, WebP), 品質, サイズを変更でき, 出力サイズをプレビューできます. アルバムや AutoJs6 のファイルエクスプローラーで複数の画像を選ぶと一括変換できます.

### スクリプトでの使い方

AutoJs6 スクリプトでは `gallery` モジュールを通じて本プラグインを呼び出します. 次の例では, ユーザーに最大 5 枚の画像を選ばせ, 長辺 1080 ピクセルの WebP に変換してから, ビューアーで結果を表示します:

```js
let images = gallery.pick({ multiple: true, maxCount: 5 });
if (images) {
    let outputs = images.map((image) => gallery.convert(image.path, { format: 'webp', longEdge: 1080 }).path);
    gallery.view(outputs);
}
```

- どのメソッドにも Promise を返す非同期版があります (例: `gallery.pickAsync`). 同期版の `pick`, `edit`, `convert` は長時間待機することがあるため, UI スレッドでは呼び出せません.
- 画像はファイルパスで指定し, 相対パスはスクリプトの作業ディレクトリを基準に解決されます. 出力は既定で元の画像の隣に書き出され (ファイル名に `_converted` または `_edited` が付きます), `output` オプションで場所を指定することもできます.
- 画像の選択にはプラグインの写真へのアクセスが必要で, 選択画面が先に許可を求めます. 選択, 表示, 編集はプラグインの画面を開くため, AutoJs6 の画面が表示されている間にスクリプトを実行すると確実です.
- 実行前に `gallery.isAvailable()` でプラグインが使えることを確認できます. すべてのオプションとエラーコードは [AutoJs6 ドキュメント > gallery](https://docs.autojs6.com/#/gallery) を参照してください.

### 動作要件

- Android 7.0 以降. HEIC と HEIF の画像には Android 9 以降, AVIF の画像には Android 12 以降が必要です.
- AutoJs6 での利用 (ファイルエクスプローラーと `gallery` モジュール) には AutoJs6 6.8.0 以降が必要で, "プラグインセンター" で本プラグインを有効にする必要があります. 単独で使う場合は AutoJs6 は不要です.
- 写真へのアクセスは, ホームでアルバムごとに画像を閲覧するときと, スクリプトが画像を選ぶときに使います. AutoJs6 のファイルエクスプローラーや他のアプリから画像を開くときは権限を求めません.
- "すべてのファイルへのアクセス" と "メディアの管理" は任意の権限で, アルバムの非表示と, 画像を削除または移動するたびの確認を省くために使います. "設定" > "ストレージ権限" でオンにします.

### よくある質問

**写真へのアクセスを許可していない場合の使い方**

ホームに "画像を選択" と "フォルダーを選択" が表示され, システムの選択画面から画像を表示, 編集, 変換できます. 後から "設定" > "ストレージ権限" で許可できます. Android 14 以降で一部の写真だけを許可した場合, ホームにはそれらの写真だけが表示され, "選択した写真を管理" で追加や削除ができます.

**ファイルメニューに "画像を編集" と "画像を変換" がない場合の対処**

AutoJs6 6.8.1 以降では, この 2 つの項目はファイルメニューの 3-Maple Image サブメニューにあります. それでも見つからない場合は, "プラグインセンター" でプラグインが有効になっていること, ファイルが対応する画像形式であることを確認し, AutoJs6 を最新版に更新してください.

**削除した画像の復元**

アルバムで削除した画像は, まずホーム右上のメニューにある "ゴミ箱" に入り, そこから復元できます. 約 30 日後に自動的に消去されます. AutoJs6 から開いて削除した画像は AutoJs6 のゴミ箱に入り, AutoJs6 で復元します.

**写真の位置情報の表示と保持**

座標は既定で表示されず, 編集, 変換, "コピーを共有" で作成した画像からも位置情報が削除されます. "設定" で "位置情報を表示" をオンにすると, 詳細に座標が表示されて "地図で開く" も使えるようになり, 保存や変換のときに "位置情報を残す" を選べます. 本プラグインにはネットワーク権限がありません.

詳しい機能説明, 対応形式, よくある質問は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Maple-Image) を参照してください.
