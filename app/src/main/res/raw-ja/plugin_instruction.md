# 画像ツール

Image Toolsはファイルマネージャーに `画像を編集` と `画像を変換` の2つのアクションを提供します.

エディターは切り抜き, 回転, 水平および垂直反転, 明るさ, コントラスト, 彩度, 色温度, ブラシ, テキスト, 元に戻す操作に対応します. コンバーターはJPEG, PNG, WebP出力, 品質, 拡大縮小, 縦横比固定, JPEG背景選択に対応します.

このプラグインにはホストビルド5269以降が必要です.

安全性とプライバシーの制限:

- ソースは正確な読み取り専用 `content` URIでのみ開かれます.
- 出力はホスト所有の正確な出力トランザクションURIにのみエンコードされます.
- ソースの隣へ直接書き込まず, 任意のURIを返しません.
- 出力はJPEG, PNG, WebPのいずれかで, 最大256 MiBです.
- ストレージ権限とネットワーク権限を要求しません.
