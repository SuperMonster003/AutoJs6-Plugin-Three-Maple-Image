# 图像工具

图像工具为文件管理器提供 `编辑图像` 和 `转换图像` 两个动作.

编辑器支持裁剪, 旋转, 水平和垂直翻转, 亮度, 对比度, 饱和度, 色温, 画笔, 文字和撤销. 转换器支持 JPEG, PNG 和 WebP 输出, 质量控制, 百分比或自定义缩放, 比例锁定及 JPEG 背景选择.

插件需要宿主构建版本 5269 或更高版本.

安全和隐私限制:

- 仅通过精确的只读 `content` URI 访问打开源文件.
- 仅向宿主拥有的精确输出事务 URI 编码.
- 插件不会在源文件旁写入, 也不会返回任意 URI.
- 编码输出仅限 JPEG, PNG 或 WebP, 且最大为 256 MiB.
- 插件不请求存储或网络权限.
