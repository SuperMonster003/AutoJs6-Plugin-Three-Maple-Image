# 圖像工具

Image Tools 為 AutoJs6 Explorer 提供 `編輯圖像` 和 `轉換圖像` 兩個 overflow 動作.

編輯器支援裁剪, 旋轉, 水平和垂直翻轉, 亮度, 對比度, 飽和度, 色溫, 畫筆, 文字和復原. 轉換器支援 JPEG, PNG 和 WebP 輸出, 品質控制, 百分比或自訂縮放, 比例鎖定及 JPEG 背景選擇.

插件需要 AutoJs6 構建版本 5269 或更高版本. 插件完全使用 JVM 實現, 與裝置 ABI 無關.

安全和私隱限制:

- 僅透過精確的唯讀 `content` URI 存取開啟來源檔案.
- 僅向宿主擁有的精確輸出事務 URI 編碼.
- 插件不會在來源檔案旁寫入, 也不會返回任意 URI.
- 編碼輸出僅限 JPEG, PNG 或 WebP, 且最大為 256 MiB.
- 插件不要求儲存或網絡權限.
