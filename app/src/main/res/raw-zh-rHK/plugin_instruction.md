# AutoJs6 3-Maple Image

Image Viewer 與 Image Tools 合併為 3-Maple Image, 在同一應用程式提供圖片檢視, 編輯與格式轉換.
統一設定頁提供語言, 夜間模式, 主題色及四種啟動器圖示選項.
應用程式 ID 從 io.github.supermonster003.autojs6.plugin.imageviewer / io.github.supermonster003.autojs6.plugin.imagetools 改為 io.github.supermonster003.autojs6.plugin.three.maple.image. Android 將其視為獨立應用程式, 原應用程式與資料可以保留, 設定不會自動遷移.


3-Maple Image 為檔案管理器中的 AVIF, BMP, GIF, HEIC, HEIF, JFIF, JPE, JPEG, JPG, PNG 和 WEBP 檔案提供圖像主要動作.

HEIC 與 HEIF 需要 Android 9 或更新版本, AVIF 需要 Android 12 或更新版本. 平台解碼器不可用時, 檢視器會顯示明確的版本或能力提示, 而非靜默失敗.

超大 JPEG, PNG 與靜態 HEIC/HEIF 會使用有界的低取樣預覽, 放大時只解碼目前可見的高清區域. 翻頁或記憶體受壓時會立即釋放圖塊快取.

如要只開啟明確選取的一組圖像, 請在 AutoJs6 進入多選模式, 從同一目錄選取 1 至 128 張受支援圖像並點按 `檢視圖像`. 檢視器保留選取順序, 左右翻頁只會在這組已選圖像內進行; 每個已選 URI 都會獨立校驗並一直保持唯讀. 選取的每一張都可用底列的 `刪除` 移入 AutoJs6 回收站, 並可復原; 點擊單一檔案開啟的圖像同樣可以刪除, 同一目錄的其他圖像則不能.

檢視器將圖像配合螢幕顯示, 並支援在 1 倍狀態下左右滑動瀏覽同一目錄圖像, 焦點捏合縮放, 平移, 雙擊在配合螢幕與以觸點為中心的 2.5 倍之間切換, 以及逐頁中繼資料. 捏合期間及雙擊後會短暫顯示目前倍率. GIF 動圖循環播放並顯示暫停/繼續控制項, 靜態圖不會顯示該控制項. 圖像鋪滿整個螢幕並延伸至半透明浮層欄下方; 點擊圖像可以隱藏或顯示浮層, 開啟多張圖像時標題欄還會顯示 `3 / 12` 形式的頁碼. 分享和使用其他應用程式開啟僅在最初開啟的圖像頁可用, 經工作階段開啟的同層頁會停用這兩個動作. 雙擊倍率與最大倍率, 單指縮放, 點按邊緣翻頁, 下滑關閉等手勢可在 3-Maple Image 的 `設定` > `檢視器` 中調整.

`旋轉` 只會旋轉目前顯示並保留已有縮放. 右上角選單中的 `重設縮放` 會同時恢復原始方向與配合螢幕.

點按 `詳情` 可開啟底部面板, 查看檔案名稱, MIME 類型, 大小, 解像度以及能讀取到的 EXIF 拍攝時間, 裝置, 曝光與方向. 偵測到 GPS 中繼資料時預設只提示其存在; 開啟 `設定` > `檢視器` > `顯示位置資訊` 後顯示拍攝地點的座標 (十進制與度分秒), 並可 `在地圖中開啟`.

資訊欄始終顯示 MIME 類型, 檔案大小與解碼解像度. Android 8.0 或以上且解碼器可提供時, 還會顯示解碼像素位深 (bpp) 與輸出色彩空間.

相片會按 EXIF 方向自動旋轉或鏡像. `旋轉` 會在糾正後的顯示上繼續疊加只影響檢視的旋轉.

右上角選單中的 `列印 / 儲存 PDF` 會把完整的目前圖像交給 Android 系統列印面板, 保留 EXIF 糾正與手動檢視旋轉. GIF 動圖採用點按時正在顯示的影格. 縮放和平移不會裁剪輸出, 插件亦不會建立臨時圖像或 PDF 檔案.

在檔案管理員的目錄選單中選擇 `以相簿瀏覽`, 可經主程式工作階段把該目錄作為相簿開啟: 最多 8 層子資料夾顯示為資料夾區塊, 圖像在檢視器中開啟並可在該資料夾內左右翻頁, 每個資料夾只列出前 4096 項. 此模式不需要儲存權限, 也不會披露檔案路徑; 其中不提供管理操作.

檔案選單中的 `編輯圖像` 與 `轉換圖像` 預設在原檔案旁產生新檔案; 在儲存對話框或轉換頁開啟 `覆蓋原圖` 後會取代原圖 (格式不變), 8 秒內可復原. 每個輸出都先暫存並讀回校驗後才發佈, 失敗時不會留下半成品.

需要主程式組建版本 5352 或更新版本.

安全和私隱限制:

- 選中來源檔案使用臨時唯讀 `content` URI; 同一目錄的直屬檔案只能透過限域的主程式 `readSiblings` 工作階段開啟.
- 大於 8 TiB 的檔案會被拒絕.
- 從 AutoJs6 開啟時外掛程式不要求任何權限, 外掛程式也不宣告網絡權限.
- 刪除只會把你選取的檔案移入 AutoJs6 回收站; 移動, 重新命名與檔案資料仍由主程式提供.
