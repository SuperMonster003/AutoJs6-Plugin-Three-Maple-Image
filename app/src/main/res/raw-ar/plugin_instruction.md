# أدوات الصور

يوفر Image Tools إجرائي overflow باسم `تحرير الصورة` و `تحويل الصورة` في AutoJs6 Explorer.

يدعم المحرر الاقتصاص والتدوير والقلب والسطوع والتباين والتشبع وحرارة اللون والفرشاة والنص والتراجع. يدعم المحول إخراج JPEG و PNG و WebP والجودة وتغيير الحجم وقفل النسبة وخلفية JPEG.

يتطلب الملحق AutoJs6 build 5269 أو أحدث. تم تنفيذه بالكامل على JVM ولا يعتمد على ABI الجهاز.

حدود الأمان والخصوصية:

- يفتح المصدر فقط عبر URI من نوع `content` دقيق وللقراءة فقط.
- يشفر الإخراج فقط إلى URI معاملة الإخراج الدقيقة التي يملكها المضيف.
- لا يكتب الملحق بجوار المصدر ولا يعيد URI عشوائيا.
- يقتصر الإخراج على JPEG أو PNG أو WebP وبحد أقصى 256 MiB.
- لا يطلب الملحق إذن التخزين أو الشبكة.
