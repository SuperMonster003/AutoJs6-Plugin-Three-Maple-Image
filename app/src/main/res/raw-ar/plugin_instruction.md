# أدوات الصور

Image Tools (أدوات الصور) هو ملحق لمعالجة الصور مخصص لمدير ملفات AutoJs6. بعد تفعيله يظهر لكل ملف صورة في مدير الملفات إجراءان في القائمة المنبثقة: `تحرير الصورة` يفتح محررا بلوحة رسم وشريط أدوات للتعديلات اليومية (اقتصاص, تدوير, ضبط الألوان, رسم), و `تحويل الصورة` يفتح مربع حوار يحفظ الصورة بصيغة JPEG أو PNG أو WebP مع إمكانية تغيير حجمها.

تحفظ النتيجة دائما كملف جديد بجوار الملف الأصلي (يضاف إلى اسمه اللاحقة `edited` أو `converted`). يبقى الملف الأصلي للقراءة فقط طوال الوقت ولا يتم تعديله أو استبداله أو حذفه أبدا. لا يطلب الملحق أي أذونات تخزين أو شبكة, ولا يمكنه الوصول إلا إلى ملف إدخال واحد وموقع إخراج واحد يصرح بهما المضيف.

## التثبيت والاستخدام

تحقق من المتطلبات التالية قبل البدء:

```text
minimum host build: 5269
minimum android: 7.0 (API 24)
```

1. نزل ملف APK الخاص بالملحق وثبته. لا يملك الملحق أيقونة تشغيل, وبعد التثبيت يديره AutoJs6 بالكامل.
2. افتح AutoJs6 وادخل إلى `مركز الاضافات`, ثم ابحث عن `أدوات الصور` وفعله.
3. في مدير ملفات AutoJs6 حدد أي ملف صورة (مثل `photo.jpg`) وافتح قائمته المنبثقة.
4. اختر `تحرير الصورة` لدخول المحرر, أو اختر `تحويل الصورة` لفتح مربع حوار التحويل.

يوفر شريط المحرر `اقتصاص` و `تدوير لليسار` و `تدوير لليمين` و `تدوير دقيق` و `قلب أفقي` و `قلب رأسي` و `السطوع` و `التباين` و `التشبع` و `حرارة اللون` و `فرشاة` و `نص`. يتضمن الاقتصاص نسبا حرة وثابتة ونسبة الأصل; ويتراوح التدوير الدقيق من -45° إلى +45°. أنواع الفرشاة هي القلم وقلم التمييز والفسيفساء والممحاة; ويدعم النص عدة أسطر وحدا وظلا. يوفر الشريط العلوي `تراجع` و `إعادة` و `حفظ`, وتوفر القائمة الإضافية `استعادة الصورة الأصلية`. يفتح `حفظ` مربع حوار لاتباع تنسيق المصدر أو اختيار JPEG / PNG / WebP وضبط جودة الضغط مع فقدان وتفعيل WebP بلا فقدان على Android 11+. ينشر المضيف ملفا مجاورا جديدا باللاحقة `edited`; تزال بيانات المصدر الوصفية ولا يستبدل الملف الأصلي أبدا.

يوفر مربع حوار التحويل JPEG / PNG / WebP (PNG افتراضيا) والجودة 1-100 (الافتراضي 92) و WebP بلا فقدان على Android 11+ و `حجم الملف المستهدف` الذي يختار الجودة تلقائيا لـ JPEG أو WebP مع فقدان. يوفر `تغيير الحجم` أوضاع `الأصلي` و `النسبة المئوية` (1-1000) و `الضلع الطويل` (1920 بكسل افتراضيا ومن دون تكبير) و `مخصص` مع قفل اختياري للنسبة. يمكن لـ JPEG ملء الشفافية بالأبيض أو الأسود; ويستخدم PNG لوحة مفهرسة تلقائيا إذا لم تتجاوز النتيجة 256 لونا. يكون `الاحتفاظ ببيانات EXIF الآمنة` معطلا افتراضيا ويزيل دائما GPS والمعاينات المضمنة والبيانات التي لا يمكن فحصها بأمان. يعرض مربع الحوار الدقة والحجم المتوقع واللاحقة. يطلب `تحويل` من المضيف نشر ملف مجاور باللاحقة `converted`; ولا ينشئ `إلغاء` أو الرجوع أي ملف.

## التنسيقات المدعومة

يعرض مدير الملفات إجراءات الملحق للملفات ذات الامتدادات التالية (وأي نوع MIME من فئة `image/*`):

```text
input:  bmp, gif, heic, heif, jpg, jpeg, png, webp (image/*)
output: JPEG (jpg), PNG (png), WebP (webp)
```

يتعرف الملحق على الصور من محتواها ولا يثق بالامتدادات: نجاح الفتح يعتمد على قدرة Android على فك ترميز الملف. الملفات المتحركة مثل GIF و WebP المتحرك تعالج بإطارها الأول فقط; وحد ملف الإدخال وملف الإخراج 256 MiB لكل منهما.

## الأمان

بني الملحق على مبدأ الرفض الافتراضي. جميع التدابير التالية مفعلة دائما ولا يمكن تعطيلها:

- الملف الأصلي للقراءة فقط بصرامة: يفتح الملحق الإدخال حصرا عبر content URI للقراءة فقط يمنح لمرة واحدة من المضيف, ولا يستلم مسارات نظام الملفات, ولا يطلب أذونات تخزين أو شبكة.
- يكتب الإخراج فقط في الموقع المحدد الذي أنشأه المضيف مسبقا, وعند النجاح لا يعيد الملحق سوى معرف المعاملة; ولا يمكنه اختيار أو إنشاء أو إعادة أي URI آخر.
- كل معاملة إخراج تستخدم لمرة واحدة: تسجل المعرفات المستخدمة بشكل دائم, وترفض الطلبات المكررة أو المعادة فورا.
- يتحقق من كل استدعاء بالكامل: أي عدم تطابق في إصدار البروتوكول أو مصدر الاستدعاء أو معرف الإجراء أو وضع منح الأذونات أو نوع MIME أو الاسم المعروض أو معرف المعاملة يوقف التنفيذ, كما يرفض أي منح لصلاحية الكتابة على الملف الأصلي.
- الإدخال والإخراج محدودان بـ 256 MiB لكل منهما, ودقة الإخراج محدودة بـ 16384 px للضلع الواحد و 40 MP إجمالا, ويراقب عدد البايتات المرمزة أثناء الكتابة مباشرة.
- يزيل الإخراج المعاد ترميزه بيانات المصدر الوصفية افتراضيا. يستخدم الاحتفاظ الاختياري ببيانات EXIF الآمنة قائمة سماح محدودة; ويطبع الاتجاه, بينما يزال دائما موقع GPS والمعاينات المضمنة والبيانات الوصفية التي لا يمكن فحصها بأمان.
