# Просмотр изображений

Image Viewer предоставляет основное действие для изображений BMP, GIF, JFIF, JPE, JPEG, JPG, PNG и WEBP в Проводнике AutoJs6.

Средство просмотра вписывает изображение в экран и поддерживает масштабирование щипком вокруг фокуса, перемещение, сброс двойным нажатием, метаданные, отправку и открытие в другом приложении. Нажмите изображение, чтобы скрыть или показать элементы управления.

Плагину требуется сборка AutoJs6 5269+. Он полностью реализован на JVM и не зависит от ABI устройства.

Ограничения безопасности и конфиденциальности:

- Источник открывается через временный доступ только для чтения к URI `content`.
- Файлы больше 8 TiB отклоняются.
- Плагин не запрашивает разрешения хранилища или сети.
- Редактирование, преобразование, удаление, перемещение и переименование остаются функциями хоста.
