# Инструменты изображений

Image Tools предоставляет действия overflow `Редактировать изображение` и `Преобразовать изображение` в AutoJs6 Explorer.

Редактор поддерживает обрезку, поворот, отражение, яркость, контраст, насыщенность, цветовую температуру, кисть, текст и отмену. Конвертер поддерживает JPEG, PNG и WebP, качество, изменение размера, фиксацию пропорций и фон JPEG.

Плагину требуется AutoJs6 build 5269+. Он полностью реализован на JVM и не зависит от ABI устройства.

Ограничения безопасности и конфиденциальности:

- Источник открывается только через точный URI `content` с доступом только для чтения.
- Вывод кодируется только в точный URI транзакции, принадлежащий хосту.
- Плагин не пишет рядом с источником и не возвращает произвольный URI.
- Вывод ограничен JPEG, PNG или WebP и размером 256 MiB.
- Плагин не запрашивает разрешения хранилища или сети.
