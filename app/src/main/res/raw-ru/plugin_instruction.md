# Image Tools

Image Tools - это плагин обработки изображений для файлового менеджера AutoJs6. После включения у каждого файла изображения в файловом менеджере появляются два действия в дополнительном меню: `Редактировать изображение` открывает редактор с холстом и панелью инструментов для повседневных правок (обрезка, поворот, цветокоррекция, рисование), а `Преобразовать изображение` открывает диалог, который сохраняет изображение в JPEG, PNG или WebP, при желании изменяя его размер.

Результат всегда сохраняется как новый файл рядом с исходным (его имя получает суффикс `edited` или `converted`). Исходный файл все время остается доступным только для чтения и никогда не изменяется, не перезаписывается и не удаляется. Плагин не запрашивает разрешений на хранилище и сеть и может обращаться только к одному входному файлу и одному месту вывода, разрешенным хостом.

## Установка и использование

Перед началом проверьте следующие требования:

```text
minimum host build: 5269
minimum android: 7.0 (API 24)
```

1. Скачайте и установите APK плагина. У плагина нет значка запуска; после установки им полностью управляет AutoJs6.
2. Откройте AutoJs6, зайдите в `Центр плагинов`, найдите `Инструменты изображений` и включите его.
3. В файловом менеджере AutoJs6 найдите любой файл изображения (например `photo.jpg`) и откройте его дополнительное меню.
4. Выберите `Редактировать изображение`, чтобы войти в редактор, или `Преобразовать изображение`, чтобы открыть диалог преобразования.

Панель редактора содержит `Обрезка`, `Повернуть влево`, `Повернуть вправо`, `Точный поворот`, `Отразить по горизонтали`, `Отразить по вертикали`, `Яркость`, `Контрастность`, `Насыщенность`, `Цветовая температура`, `Кисть` и `Текст`. Обрезка имеет свободные, фиксированные и исходные пропорции; точный поворот работает от -45° до +45°. Кисти: карандаш, маркер, мозаика и ластик; текст поддерживает несколько строк, контур и тень. Верхняя панель содержит `Отменить`, `Повторить`, `Сохранить`, а дополнительное меню - `Восстановить оригинал`. `Сохранить` открывает диалог для исходного формата или JPEG / PNG / WebP, качества с потерями и WebP без потерь на Android 11+. Хост публикует новый соседний файл с суффиксом `edited`; исходные метаданные удаляются, оригинал не перезаписывается.

Диалог преобразования предлагает JPEG / PNG / WebP (по умолчанию PNG), качество 1-100 (по умолчанию 92), WebP без потерь на Android 11+ и `Целевой размер файла`, автоматически выбирающий качество JPEG или WebP с потерями. `Изменить размер` предлагает `Исходный`, `Процент` (1-1000), `Длинная сторона` (по умолчанию 1920 px, без увеличения) и `Пользовательский` с необязательной фиксацией пропорций. JPEG заполняет прозрачность белым или черным; PNG автоматически использует индексированную палитру, если результат содержит не более 256 цветов. `Сохранять безопасные метаданные EXIF` по умолчанию выключено и всегда удаляет GPS, встроенные эскизы и метаданные, которые нельзя безопасно проверить. Диалог показывает разрешение, ожидаемый размер и суффикс. `Преобразовать` просит хост опубликовать соседний файл с суффиксом `converted`; `Отменить` или назад не создает файл.

## Поддерживаемые форматы

Файловый менеджер показывает действия плагина для файлов со следующими расширениями (и любым MIME-типом `image/*`):

```text
input:  bmp, gif, heic, heif, jpg, jpeg, png, webp (image/*)
output: JPEG (jpg), PNG (png), WebP (webp)
```

Плагин распознает изображения по содержимому и не доверяет расширениям: откроется ли файл, зависит от того, сможет ли Android его декодировать. Анимированные файлы, такие как GIF и анимированный WebP, обрабатываются только по первому кадру; входной и выходной файлы ограничены 256 MiB каждый.

## Безопасность

Плагин построен по принципу запрета по умолчанию. Все перечисленные меры всегда активны и не могут быть отключены:

- Исходный файл строго только для чтения: плагин открывает вход исключительно через одноразовый content URI только для чтения, выданный хостом, не получает путей файловой системы и не запрашивает разрешений на хранилище и сеть.
- Вывод записывается только в точное место, заранее созданное хостом, и при успехе плагин возвращает лишь идентификатор транзакции; он не может выбрать, создать или вернуть какой-либо другой URI.
- Каждая транзакция вывода одноразовая: использованные идентификаторы записываются постоянно, а повторные или продублированные запросы отклоняются сразу.
- Каждый вызов полностью проверяется: несовпадение версии протокола, источника вызова, идентификатора действия, режима выдачи прав, MIME-типа, отображаемого имени или идентификатора транзакции прерывает выполнение, а права на запись в исходный файл также отклоняются.
- Вход и выход ограничены 256 MiB каждый, выходное разрешение - 16384 px на сторону и 40 MP в сумме, а число закодированных байтов контролируется прямо во время записи.
- Заново закодированный вывод по умолчанию удаляет метаданные источника. Дополнительное безопасное сохранение EXIF использует ограниченный список разрешенных полей; ориентация нормализуется, а GPS-координаты, встроенные миниатюры и метаданные, которые нельзя безопасно проверить, удаляются всегда.
