# 3-Maple Image v3.1.0 发布准备

状态: 功能完成, 待维护者确认发布 (2026-10-14). 版本号尚未改为 3.1.0, changelog 尚未并入 `.changelog/lang_*.json`.

## 版本与兼容性

- 应用 ID 不变: `io.github.supermonster003.autojs6.plugin.three.maple.image`
- Android: 最低 7.0 / API 24, targetSdk 与 compileSdk 37
- AutoJs6: 最低 build 不变 (explorer-action 协议仍为 v12); 宿主入口的删除随 3.1.1 与宿主 v24 一起提供
- 新权限: `MANAGE_MEDIA` (Android 12+ 特殊应用权限 "媒体管理", 只能由用户在系统设置开启, 默认关闭); 仍不声明 `INTERNET`
- 新依赖: Room 2.8.1 (运行库, KTX, 编译期 KSP 处理器), 数据库 `maple.db` 位于应用私有目录, `allowBackup=false`

## 可直接用于 Release 的摘要

3-Maple Image v3.1.0 让相册可以管理图片:

- 长按图片进入多选, 不抬手拖动可选中一段, 支持全选与反选; 可分享, 收藏, 移动, 复制, 删除, 重命名和查看详情.
- 删除的图片先进入回收站, 底部提示可撤销; 回收站在首页右上角菜单中, 可恢复, 永久删除或清空. Android 11 及以上使用系统回收站, Android 7-10 使用应用自己的回收站.
- 移动和复制可选择相册或新建相册, 最近用过的相册排在前面; 遇到同名图片时询问一次: 保留两者, 跳过或替换. 移动和重命名可撤销.
- "收藏" 相册排在相册列表最前; 查看器顶栏新增心形按钮, 底栏的 "删除" 取代 "其他应用" (移到右上角菜单, 与重命名, 移动, 复制在一起).
