# 3-Maple Image v3.2.0 发布记录

状态: 已发布 (2026-10-15, 维护者授权由我执行 P1-P5): tag `v3.2.0` = `90800e3`, versionCode 173, GitHub Release 为 Latest, 官方索引 `173.json` (索引提交 `cd7852f`).

## 版本与兼容性

- 应用 ID 不变: `io.github.supermonster003.autojs6.plugin.three.maple.image`
- Android: 最低 7.0 / API 24, targetSdk 与 compileSdk 37
- AutoJs6: 两份目录 (查看器与工具) 都声明 explorer-action 协议 24, 最低宿主构建号 5352 (`REQUIRED_HOST_VERSION`, 索引生成器从 APK 读出 `requiresHostVersion` 5352). 宿主构建号自 2026-10-12 起就是 5352, 10-12 到 10-14 的开发版同号却不支持 v24; 另外宿主在 2026-10-15 修复了 "删除过一次后插件动作全部无法启动" (AutoJs6 本地提交 `8794cf3e72`), 所以 changelog 写的是 2026-10-15 及以后的开发版或正式版. 不支持协议 24 的宿主会忽略本插件的全部文件管理器动作.
- 插件内置的 `explorer-action-api.aar` 从宿主当前源码 (`:plugin-api:explorer-action-api`) 编出, 含 v24 `targetTrash`
- 权限不变: 仍不声明 `INTERNET`; 覆盖原图在 Android 11+ 经系统写入确认 (`createWriteRequest`), Android 7-10 直接写内部存储中的文件

见 GitHub Release 说明: 编辑器重做 (六组工具, 画布缩放平移, 14 种滤镜, 6 项新调整, 调整尺寸, 标注形状, 长按取色), 覆盖原图与撤销, 查看器旋转后保存 (JPEG 无损), 转换器与批量转换共用表单, AutoJs6 文件管理器中的覆盖与删除 (移入 AutoJs6 回收站), 以及三项修复.

## 后续

- 撤销覆盖或旋转保存时 Android 11+ 会再弹一次系统写入确认 (每次写入都单独申请 `createWriteRequest`); 维护者决定放到 3.2.0 之后的版本修复.
- 横屏小屏手机上编辑器面板最多占顶栏以下区域的一半, 其余控件需要在面板内滚动; 更合适的横屏布局 (例如侧栏) 留给 M5 的 9.3 "平板, 横屏与多窗口".
