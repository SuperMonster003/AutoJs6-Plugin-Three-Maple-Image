## 可直接用于 Release 的摘要

Image Viewer v1.1.0 将单文件只读查看扩展为完整但仍保持限域的图像浏览体验:

- 在 1 倍状态下按自然文件名顺序左右浏览同目录图像, 或按宿主选择顺序打开最多 128 张明确选中的图像.
- 增加双击 2.5 倍、90 度视图旋转、实时倍率提示及 GIF 暂停/继续, 并保留焦点捏合与平移.
- 增加按需 EXIF 详情、全部 8 种 EXIF 方向纠正、GPS 坐标隐藏、解码位深/色彩空间及打印/保存 PDF.
- 增加 HEIC / HEIF / AVIF 支持与真实解码能力探针; 超大 JPEG / PNG / 静态 HEIC / HEIF 使用有界预览和可见区域瓦片.
- 所有入口继续执行严格的请求、目标、内容、大小与直属关系校验, 只使用临时只读授权, 不申请存储或网络权限.
- 界面、说明、README 与 CHANGELOG 覆盖 10 种语言, README 包含五张真实 Android UI 截图.

重要兼容性提示: 同目录浏览与明确多选依赖 explorer-action v12, 因此本版本需要 AutoJs6 build 5276 或更高版本.
