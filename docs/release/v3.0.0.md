# 3-Maple Image v3.0.0 发布准备

状态: 发布候选. ROADMAP 6.1-6.5 已完成 (6.5 只差推送后的 GitHub CI); 5 万张大库在两台真机达标后, `VERSION_NAME` 已改为 3.0.0 并把下面的 changelog 并入 `.changelog` (2026-10-13). 剩余: P3 冒烟记录, P4 / P5 由维护者执行.

## 版本与兼容性

- 应用 ID 不变: `io.github.supermonster003.autojs6.plugin.three.maple.image`
- Android: 最低 7.0 / API 24, targetSdk 与 compileSdk 37
- AutoJs6: 最低 build 不变 (explorer-action 协议仍为 v12); 新目录动作 "以相册浏览" 不需要宿主升级
- 新权限: `READ_MEDIA_IMAGES`, `READ_MEDIA_VISUAL_USER_SELECTED`, `READ_EXTERNAL_STORAGE` (API <= 32), `WRITE_EXTERNAL_STORAGE` (API <= 29), `MANAGE_EXTERNAL_STORAGE` (特殊应用权限, 只能由用户在系统设置开启); 仍不声明 `INTERNET`
- 新依赖: Navigation Compose 2.10.2

## 可直接用于 Release 的摘要

3-Maple Image v3.0.0 把独立首页变成相册:

- 按文件夹浏览设备上的图片, 可切换为所有图片的平铺视图; 网格 3-6 列, 排序按相册记住, 快速滚动条带日期提示.
- 查看器在整个相册中左右翻页, 底部缩略图条点按跳转, 返回时网格停在最后查看的图片; 双指旋转后对齐到 90 度 (仅显示).
- 独立首次启动只申请一次照片权限, 拒绝后仍能通过系统选择器查看, 编辑和转换; Android 14 及以上支持只授权部分照片; 设置 > 存储权限 统一管理授权, 已授权文件夹与可选的所有文件访问. 从 AutoJs6 或其他应用打开图片从不申请权限.
- AutoJs6 文件管理器的文件夹菜单新增 "以相册浏览".
