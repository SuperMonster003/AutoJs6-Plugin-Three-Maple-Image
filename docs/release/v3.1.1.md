# 3-Maple Image v3.1.1 发布准备

状态: 已发布 (2026-10-14, 维护者授权由我执行 P1-P5): tag `v3.1.1` = `d0dc1b9`, versionCode 147, GitHub Release 为 Latest, 官方索引 `147.json` (索引提交 `388e059`).

## 版本与兼容性

- 应用 ID 不变: `io.github.supermonster003.autojs6.plugin.three.maple.image`
- Android: 最低 7.0 / API 24, targetSdk 与 compileSdk 37
- AutoJs6: 最低 build 不变 (explorer-action 协议仍为 v12); 宿主入口删除等宿主 v24 发布后随后续版本提供
- 权限不变 (隐藏相册使用已声明的 `MANAGE_EXTERNAL_STORAGE`, 只能由用户在系统设置开启); 仍不声明 `INTERNET`
- 数据库 `maple.db` 升到版本 2 (新表 `folder_marks`, 自动迁移, 3.1.0 的收藏与回收站记录保留)
- 新增一个不导出的 FileProvider (`.hidden-images`, 仅内置存储), 只在浏览隐藏文件夹时按单个文件授权

## 可直接用于 Release 的摘要

3-Maple Image v3.1.1 让相册更好整理和查找:

- 相册列表支持多选: 长按相册后可置顶, 排除, 隐藏, 删除整个相册 (进入回收站, 可撤销) 或重命名相册.
- 排除只影响本图库; 隐藏会写入 .nomedia, 其他图库也看不到. 设置中可查看和恢复已排除与隐藏的文件夹.
- 排序改为对话框, 新增随机排序和按日 / 按月分组, 可只对当前相册生效; 相册列表的排序会被记住.
- 新增搜索: 首页按相册名和文件名搜索, 相册内按文件名筛选.
- 修复存储卡上的图片在移动和复制时放错位置的问题.
