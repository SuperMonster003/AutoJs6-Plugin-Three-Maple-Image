## 可直接用于 Release 的摘要

AutoJs6 脚本现在可以通过 `gallery` 对象使用 3-Maple Image: `gallery.pick` 打开选图界面让你选择一张或多张图片, 脚本得到图片的路径, 尺寸, 大小和拍摄时间; `gallery.view` 用查看器显示脚本指定的图片, 脚本知道你正在看第几张; `gallery.edit` 打开编辑器, 你保存后由 AutoJs6 写出结果; `gallery.convert` 不显示界面, 按转换器的选项转换图片. 图片由 AutoJs6 打开后交给插件, 结果也由 AutoJs6 写入, 所以脚本只能处理它自己能访问的文件. 需要 AutoJs6 6.8.0 构建号 5439 或更高; 文件管理器中的查看, 编辑和转换仍只需要构建号 5352. 插件仍不申请网络权限.

AutoJs6 scripts can now use 3-Maple Image through the `gallery` object: `gallery.pick` opens the picker so you can choose one or more images, and the script receives their paths, dimensions, sizes and capture times; `gallery.view` shows the images a script names in the viewer and tells the script which one you are looking at; `gallery.edit` opens the editor and AutoJs6 writes the result after you save; `gallery.convert` converts images with the converter's options without showing anything. AutoJs6 opens the images and writes the results itself, so a script only handles files it can access. Requires AutoJs6 6.8.0 build 5439 or later; viewing, editing and converting in the file manager still require build 5352. The plugin still requests no network permission.
