# 3-Maple Image v3.1.2 发布记录

状态: 已发布 (2026-10-14, 维护者授权由我执行 P1-P5): tag `v3.1.2` = `eee56fe`, versionCode 152, GitHub Release 为 Latest, 官方索引 `152.json` (索引提交 `ab3a50e`).

## 版本与兼容性

- 应用 ID 不变: `io.github.supermonster003.autojs6.plugin.three.maple.image`
- Android: 最低 7.0 / API 24, targetSdk 与 compileSdk 37
- AutoJs6: 最低 build 不变, 目录仍声明 explorer-action 协议 v12. 新增的 `convert-images` 动作 (多文件, 选择工具栏, `ACCESS_CREATE_IN_PARENT`) 用 v15 输出批次发布文件; 已发布的宿主 (5352 等) 会接受这个动作, 但多选工具栏只放一个插件按钮, 显示优先级更高的 `查看图像`, 所以要等带 "更多" 按钮的宿主 (AutoJs6 本地提交 `287b5f566c`, 待维护者合并与发布) 才能用到
- 插件内置的 `explorer-action-api.aar` 换成 Stack Archive 在用的 v21 构建 (`4938762`)
- 权限不变: 批量转换写入的是新建图片 (Android 10+ 不需要确认, Android 7-9 用已声明的存储写权限); 仍不声明 `INTERNET`, 不使用前台服务 (T12)

## 可直接用于 Release 的摘要

见 GitHub Release 说明: 批量转换 (相册内多选 -> 更多 -> 转换, 同一组设置, 写到原相册的 `原名_converted`, 进度可取消, 失败项可重试), AutoJs6 文件管理器的 `批量转换` 入口 (全部成功才一起保存, 需要带 "更多" 按钮的宿主), 以及查看器相邻页面一直加载中的修复.
