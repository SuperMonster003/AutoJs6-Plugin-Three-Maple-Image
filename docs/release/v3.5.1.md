# 3-Maple Image v3.5.1 发布草稿

状态: 未发布. 版本号按 plugin-center 第三期 T63 (下一个修订号) 暂定, 由 P21.9 发版时确定; 这一版还要带上 P18 / P21.9 重写的使用说明 (10 种语言). 发版时把下面的条目并入 `.changelog/lang_*.json` 的新版本 (放在 `improvement`), 再运行 `py .python/generate_markdown.py` 生成 CHANGELOG 与 README.

## 本版的改动 (已在 master, 只本地提交)

- 发行历史页 (plugin-center P19.1, 维护者 2026-11-18 确认为官方插件 M3 发行历史页的样板, 规范在工作区根的 `AUTOJS6_PLUGIN_RELEASE_HISTORY_AGENTS.md`): 标题 "发行历史", 子标题插件名称; 按版本展开或收起, 收起时显示日期与各类别的条目数, 展开后每个类别只标注一次, 各条前是绘制的圆点; 顶栏 "展开全部 / 收起全部"; 打开时展开最新版本; 当前语言的 CHANGELOG 缺失或解析不出版本时回退到英文.
- 查看器与编辑器菜单的 "发行历史" 打开这一页, 不再弹出显示原始文本的对话框; 设置页 "关于" 分区的那一行也改叫 "发行历史" (原为 "版本历史").
