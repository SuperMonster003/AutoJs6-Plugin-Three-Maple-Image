- 应用 ID 不变: `io.github.supermonster003.autojs6.plugin.three.maple.image`
- Android: 最低 7.0 / API 24, targetSdk 与 compileSdk 不变

## 可直接用于 Release 的摘要

转换图片时, PNG 的质量现在可以调节了. 格式为 PNG 时, 转换器, 批量转换和编辑器的保存对话框多了一个 `有损压缩` 开关 (默认关闭, 关闭时与以前一样是无损 PNG). 打开后质量滑块可用: 插件允许每个颜色通道有很小的偏差 (质量 90 及以上不超过 1 级, 最低档不超过 16 级), 换来明显更小的文件, 照片在质量 90 以上约为无损 PNG 的六成, 界面截图约为六成半到八成, 质量越低越小. 图片不会被降到 256 色, 透明度不变, 纯色区域仍是纯色, 不会出现色斑. 有损压缩的 PNG 还可以使用 `目标文件大小`, 由插件选出不超过目标的最高质量. AutoJs6 脚本的 `gallery.convert` 对 PNG 指定 `quality` 或 `targetBytes` 时同样得到有损压缩的 PNG, 都不指定时仍是无损的.

PNG quality can now be adjusted when converting images. With PNG as the format, the converter, batch conversion and the editor's save dialog offer a `Lossy compression` switch (off by default; off means lossless PNG as before). Turning it on enables the quality slider: the plugin allows a very small difference per color channel (at most 1 level at quality 90 and above, at most 16 at the lowest setting) in exchange for a clearly smaller file. Photos at quality 90 and above take about 60% of the lossless PNG, screenshots about 65% to 80%, and lower qualities are smaller still. The image is not reduced to 256 colors, transparency is unchanged, and flat areas stay flat without blotches. Lossily compressed PNG can also use `Target file size`, where the plugin picks the highest quality that stays within the target. In AutoJs6 scripts, `gallery.convert` writes a lossily compressed PNG when `quality` or `targetBytes` is given for PNG output and stays lossless when neither is.
