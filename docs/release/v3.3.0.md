## 版本与兼容性

- 应用 ID 不变: `io.github.supermonster003.autojs6.plugin.three.maple.image`
- Android: 最低 7.0 / API 24, targetSdk 与 compileSdk 37
- AutoJs6: 与 3.2.0 相同, 两份目录都声明 explorer-action 协议 24, 最低宿主构建号 5352; 本版没有宿主侧改动

- 依赖: 新增 `glide-ksp` (构建时注解处理, 生成 Glide 模块注册类); 测试新增 Accessibility Test Framework 4.1.1 与同版 Guava (只在仪器测试 APK 中)

## 可直接用于 Release 的摘要

查看器新增幻灯片 (间隔, 随机, 倒序, 循环, 切换效果, 点按暂停), 设为壁纸 (按屏幕比例裁剪, 主屏幕 / 锁定屏幕 / 两者), 分享副本 (去除元数据或缩小后分享) 与 用其他应用编辑. 设置中可以开启 显示位置信息 (详情中显示拍摄地点坐标并可在地图中打开, 保存时可选择保留位置) 与 扩展详情 (在查看器底部显示所选信息); 位置信息默认仍不显示, 保存时也照旧移除.

更多可调选项: 查看器手势 (单指缩放, 双击倍率, 最大倍率, 点按边缘翻页, 下滑关闭, 左侧滑动调节亮度) 与显示 (屏幕方向, 全屏黑底, 最高亮度, 自动隐藏系统栏, 屏幕常亮, 缩略图条, 以最高质量显示), 相册与网格 (列数, 缩略图圆角与间距, 裁剪为方形, 角标, 数量, 名称单行, 动图缩略图, 相册封面). 设置页重新分组, 原有选择全部保留.

平板, 折叠屏与横屏: 窗口足够宽时首页左边是相册列表, 右边是打开的相册, 折叠, 展开, 旋转或分屏时打开的相册不会丢失, 横屏查看器的缩略图条移到右侧. 支持键盘与遥控器 (焦点边框, 方向键翻页, 删除键删除). 读屏软件会读出每张图片的文件名和日期, 查看器浮层文字在明亮图片上更清晰, 系统 "移除动画" 也作用于查看器的翻页与幻灯片. 缩略图缓存按剩余空间限制大小, 内存紧张时释放图库占用的内存.

修复: Android 11 及以上撤销覆盖原图或旋转保存时会弹出两次系统确认; 双击后拖动缩放会先跳到 2.5 倍; Android 7 上重命名相册后会留下一个旧名称的相册. 插件仍不申请网络权限.

The viewer adds a slideshow (interval, random, reverse, loop, transitions, tap to pause), Set as wallpaper (cropped to the screen's shape, for the Home screen, the Lock screen or both), Share a copy (without metadata or smaller) and Edit with another app. Settings can turn on Show location (the details show where a photo was taken and open it in a map, and saving can keep the location) and Extended details (chosen details at the bottom of the viewer); location is still hidden by default and still removed when saving.

More to adjust: viewer gestures (one-finger zoom, double-tap zoom, maximum zoom, tap the edges to turn pages, swipe down to close, swipe on the left for brightness) and display (orientation, black background, maximum brightness, hide the system bars, keep the screen on, thumbnail strip, highest quality), and albums and grid (columns, thumbnail corners and spacing, square cropping, badges, counts, one-line names, animated thumbnails, album covers). The settings are regrouped, with every existing choice kept.

Tablets, foldables and landscape: in a wide enough window the home screen shows the album list on the left and the open album on the right, folding, unfolding, rotating or split screen keeps the open album, and the viewer's thumbnail strip moves to the right side in landscape. Keyboards and remote controls work (focus outline, arrow keys turn pages, the delete key deletes). Screen readers read each image's file name and date, the viewer's overlay text stays readable over bright images, and the system's Remove animations also covers the viewer's page turns and slideshow. The thumbnail cache is sized by the free space, and the gallery releases memory when it runs low.

Fixed: on Android 11 and later, undoing an overwrite or a saved rotation asked for the system confirmation twice; double tapping and dragging to zoom first jumped to 2.5x; on Android 7, renaming an album left an album with the old name behind. The plugin still requests no network permission.
