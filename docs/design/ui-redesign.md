# 3-Maple Image 界面重设计 (设计稿)

状态: v1.1, 2026-10-13, 第 14 节的评审问题 R1-R8 已由维护者拍板 (R5 选 2.1.0 即 5 项), 本稿为 5.1 Compose 基础设施, 共享组件库与 5.2 页面迁移的依据. 对应 [ROADMAP.md](../../ROADMAP.md) 5.1 第一条. 本稿覆盖 2.1.0 的全部页面, 并为 3.x 的相册, 网格, 分页查看器与存储权限页预留结构, 使 2.1.0 的组件不必在 3.0.0 推倒重来.

约定: 线框全部用 ASCII 字符绘制; 尺寸单位 dp, 字号单位 sp; "规范" 指 `../../../AUTOJS6_PLUGIN_STANDALONE_SETTINGS_AGENTS.md` (Three 系列独立设置页规范), 引用时写 "规范 第 N 节". 参考应用的截图只存于仓库外 `.bak/design-reference/` (见附录 A), 本文只写观察结论, 不复制其代码, 布局, 图标或字符串 (ROADMAP 红线 R1).

---

## 1. 设计目标与原则

目标: 让 3-Maple Image 从 "一个带首页的文件工具" 变成 "看图第一, 编辑随手, 设置克制" 的相册应用, 同时保持 Three 系列的中性视觉与最小权限姿态.

- P1 内容优先. 图像面永远全出血 (edge-to-edge, 延伸到系统栏下), 所有控件是半透明浮层, 单击画面即可全部隐藏. 网格页的缩略图之间只留 2 dp 间隔, 不加卡片边框.
- P2 一套组件, 五类页面. 首页, 设置, 查看器, 编辑器, 转换器共用同一组 Compose 组件 (第 6 节); 不为某一页单独造轮子.
- P3 中性表面 + 主题色强调. 页面与对话框使用规范第 6 节的中性灰阶; 主题色只用于控件, 选中态, 进度, 链接与少量重点文字. 查看器与编辑器的画布固定深色, 不随亮/暗主题与主题色变化.
- P4 可预期的手势. 单击 = 切换浮层, 双击 = 缩放切换, 捏合 = 缩放, 双指旋转 = 旋转 (3.0), 左右滑 = 翻页, 下滑 = 关闭 (3.3 设置项). 同一手势在任何页面只有一种含义.
- P5 每页五态. 每个页面都定义 加载 / 空 / 错误 / 无权限 / 部分访问 五种状态的界面 (第 10 节), 不出现空白屏.
- P6 密度与可达性按规范. 行高 >= 72 dp (双行) / 56 dp (单行), 左右留白 24 dp, 触控目标 >= 48 dp, 字号用 sp 且跟随系统, start/end 方向, TalkBack 读出角色与状态.
- P7 功能不变先焕新. 2.1.0 只换实现与视觉, 不新增能力; 允许修正第 3.3 节列出的可用性缺陷.

## 2. 参考观察

设备 QV770340J7 (Sony XQ-DQ72, Android 13, 1096 x 2560, 420 dpi), Simple Gallery Pro 6.28.1 (暗色主题, 英文界面); Fossify Gallery 以其字符串资源列出的选项为准 (未安装). 每条观察后用 "采用 / 改造 / 不采用" 标注本设计的取舍.

### 2.1 主屏 (文件夹网格)

- 顶部是一条圆角胶囊搜索栏 ("Search folders"), 右侧并排 相机, "显示所有文件夹内容", 溢出菜单 三个图标. 采用 "搜索栏 + 右侧图标" 的结构 (3.0.0); 不采用相机入口 (本插件不拍照).
- 文件夹网格 3 列 (可设 1-18 列), 封面为方形圆角缩略图, 封面上叠加小圆形角标 (置顶图钉, 锁, SD 卡), 名称与数量分两行放在封面下方. 采用 "封面下方两行文字" 与 "封面角标"; 列数范围改造为 2-5 列 (手机) 与 3-8 列 (平板), 18 列没有实际价值.
- 溢出菜单: Sort by, Filter media, Change view type, Temporarily show hidden, Temporarily show excluded, Create new folder, Open the Recycle Bin, Column count, Settings, About, More apps. 采用 排序 / 回收站 / 设置 / 关于; "临时显示隐藏与排除" 改造为一个 "显示隐藏与排除项" 开关 (3.1); 不采用 "更多应用".
- 排序对话框: 单选列表 (Name, Path, Size, Last modified, Date taken, Random, Custom) + 升/降序 + Cancel/OK. 采用同形 (去掉 Path 与 Custom, 加 "仅本相册" 复选), 对话框形态按规范第 8 节.
- 筛选对话框: 多选 (Images, Videos, GIFs, RAW, SVGs, Portraits). 本插件仅图片 (D2), 改造为 "类型角标与筛选: 全部 / 静态图 / 动图 (GIF, 动态 WEBP/AVIF)" (3.1).
- 视图类型: Grid / List + "Group direct subfolders". 不采用列表视图 (暂缓); "按直接子目录分组" 对应本插件的目录层级显示, 3.1 评估.

### 2.2 媒体网格

- 顶栏: 返回, "Search in <folder>", 文件名显示开关, 排序, 溢出. 采用; 文件名显示改为设置项而不是顶栏按钮.
- 缩略图 3 列方形, 无间隙 (1 dp), 开启文件名后在缩略图底部叠加白字渐变. 改造为 2 dp 间隔 + 可选 4 dp 圆角 (设置), 文件名叠加保留为设置项.
- 长按进入多选: 顶栏变为 "Done, 1 / 6, Delete, Share, More", 选中项右上角出现实心勾选圆点. 采用; 本设计把勾选圆点放在缩略图左上 (右上留给类型角标), 选中项加 2 dp 主题色描边并轻微缩小 (scale 0.94) 以强化反馈.
- 多选溢出: Rotate, Properties, Rename, Hide, Copy to, Move to, Create shortcut, Open with, Set as, Resize, Edit, Add to favorites, Fix Date Taken, Select all. 3.1 采用 删除 / 分享 / 移动 / 复制 / 收藏 / 重命名 / 详情 / 批量转换 / 全选; 不采用 快捷方式 与 修复拍摄日期 (暂缓).

### 2.3 查看器

- 打开后浮层可见: 顶部半透明深色条 (返回, 文件名, 旋转, 属性, 溢出); 底部左下角一个半透明小方块显示 "大小 / 分辨率 / 日期" 三行 (扩展详情); 底部一排 3 个图标按钮 (Edit, Share, Delete, 可配置). 单击画面切换浮层; 浮层隐藏时纯黑全屏. 采用 "半透明深色条 + 单击切换 + 底部图标栏"; 扩展详情叠加改造为 3.3 的设置项, 2.1.0 继续使用底栏元数据行.
- 溢出菜单 (14 项): Rename, Hide, Copy to, Move to, Create shortcut, Open with, Set as, Add to favorites, Change orientation, Print, Resize, Show on map, Slideshow, Settings. 本设计把高频动作放底栏, 低频放溢出, 溢出按里程碑逐步增加 (第 7.4 节).
- 没有缩略图条, 没有页码. 本设计 2.1.0 保留页码副标题, 3.0.0 增加缩略图条 (ROADMAP 6.3).
- 顶栏图标为纯白, 底色约 60% 不透明的深灰. 采用; 具体 token 见 5.2.

### 2.4 编辑器

Simple Gallery 的 "基础编辑器" (自有实现):

- 顶栏 "Editor" + 保存 (勾) / 用其他应用编辑 (铅笔) / 分享 三个图标. 采用 "顶栏只放 保存 / 撤销 / 重做 / 更多", 不放分享.
- 画布下方第一行是裁剪比例文字芯片 (FREE, 1:1, 4:3, 16:9, OTHER), 第二行是 5 个纯图标 (旋转, 调整大小, 裁剪, 水平翻转, 垂直翻转), 最底部 3 个纯图标标签页 (Filter, Transform, Draw). 纯图标没有文字标签, 可识别性差. 改造为 "一级分组 (图标 + 文字) + 二级工具条 (图标 + 文字) + 参数面板" 三层结构 (第 7.5 节).
- 滤镜标签页: 横向缩略图条 + 名称 (None, Struck, Clarendon, ...). 采用形态 (3.2), 名称自拟.
- 绘制标签页: 只有 "换颜色" 与 "撤销". 本插件已有画笔类型 / 宽度 / 马赛克强度, 保留并放入参数面板.

Simple Gallery 的 "高级编辑器" (第三方 SDK 界面, 仅作形态参考):

- 底部一行 图标 + 文字 的工具分组 (Transform, Filter, Adjust, Focus, Sticker, Text, ...), 横向可滚动; 选中分组后同一位置切换为该组的二级工具 (例如 Adjust: Reset, Brightness, Contrast, Saturation, Clarity, Shadows, ...), 最底部一条 "X / 组名 / 保存" 栏; 画布右下角浮动 撤销 / 重做. 采用 "图标 + 文字分组, 原位切换二级工具" 与 "画布角落浮动撤销 / 重做" (本设计放在顶栏, 画布保持干净); 旋转微调用可拖动刻度条 (Transform 面板的 0.0 刻度) 的形态采用.

### 2.5 设置页

- 单列平面列表, 大写灰色分组标题 (COLOR CUSTOMIZATION, GENERAL, VIDEOS, THUMBNAILS, SCROLLING, FULLSCREEN MEDIA, DEEP ZOOMABLE IMAGES, EXTENDED DETAILS, SECURITY, FILE OPERATIONS, BOTTOM ACTIONS, RECYCLE BIN, MIGRATING), 行为 标题 + 当前值 (两行) 或 标题 + 右侧复选框, 分组之间 1 dp 分隔线. 与规范一致处采用 (平面列表, 分组标题, 两行行); 不采用大写标题 (规范第 3 节: 分组标题 14 sp 中等字重, 不强制大写) 与复选框 (规范第 1 节: 开关项用 Material 3 Switch).
- 分组顺序以功能域为纲 (缩略图, 全屏媒体, 扩展详情, 文件操作, 回收站). 3.3 采用类似分组: 外观 -> 相册与网格 -> 查看器 -> 编辑与输出 -> 媒体管理 -> 存储权限 -> 关于 (ROADMAP 9.2).

### 2.6 Fossify Gallery 字符串中值得采纳的细节

- 查看器 "一指缩放" (双击后上下拖动), "屏幕边缘点击翻页", "下滑关闭", 都是设置项而不是默认行为: 采用 (3.3).
- "文件加载优先级: 速度 / 折中 / 质量": 改造为 "以最高质量显示" 单一开关 (3.3).
- "缩略图样式: 方形 / 圆角", "文件夹名单行": 采用 (3.3).
- "删除空文件夹": 不采用 (与 R3 "任何写入都由用户当次触发" 冲突).

### 3.3 观察到的可用性缺陷 (2.1.0 允许顺带修正)

- U1 查看器顶栏是一块接近不透明的主题色 (跟随宿主 `#FFDEAD` 时呈棕橙色), 与 "半透明浮层" 的沉浸定位不符, 深色画布上也刺眼. 改为固定深色半透明浮层 (5.2).
- U2 查看器底栏元数据行 `maxLines=1` + 居中 + 省略号, 文本超宽时首字符被裁 (实测显示 "mage/jpeg | 3.40 MB | ..."). 改为两行自适应, 超出再省略 (7.4).
- U3 编辑器工具条是 12 个纯文字按钮横向滚动, 没有分组与图标, 当前工具没有选中态. 改为三层结构 (7.5).
- U4 编辑器与转换器使用 `AppCompatSpinner` 选择比例 / 画笔类型 / 格式, 触控目标小且无当前值摘要. 改为分段按钮 (SegmentedButton) 或芯片组.
- U5 转换器是一整页可滚动表单对话框, 四种尺寸模式的输入框同时占位. 改为 "模式分段按钮 + 仅显示当前模式的输入" (7.6).
- U6 首页 hero 区 (96 dp 图标 + 两段说明) 占首屏约三分之一, 操作行没有摘要. 2.1.0 压缩 hero 高度并给操作行加一行摘要 (7.1); 3.0.0 首页整体替换为相册网格.
- U7 `ic_save_white_48dp.png` / `ic_undo_white_48dp.png` 为 PNG, 与其余 vector 图标风格不一. 统一为 24 dp 线性 vector (ROADMAP 5.2).
- U8 查看器 "详情" 按钮在动画中连点会使底部面板状态与按钮状态不同步 (本次采集中出现一次). Compose 版以单一状态源驱动.

## 5. 设计 token

### 5.1 中性色与主题色 (页面, 对话框, 设置)

按规范第 6 节, 映射到 Compose `ColorScheme`:

| 角色 | 亮色 | 暗色 | Compose 槽位 | 用途 |
| --- | --- | --- | --- | --- |
| 页面背景 | #F3F4F5 | #121212 | `background` | 首页, 设置, 网格页背景 |
| 表面 | #FFFFFF | #1E1E1E | `surface`, `surfaceContainer` | 对话框, 底部面板, 顶栏 (非浮层) |
| 主文字 | #1D1B20 | #E6E1E5 | `onSurface`, `onBackground` | 标题, 设置标题, 选项主文案 |
| 次文字 | #5F6368 | #B9BAC0 | `onSurfaceVariant` | 摘要, 说明, 分组标题 |
| 轮廓 | #C5C8CE | #777A82 | `outline` | 非交互轮廓, 输入框边框 (未聚焦) |
| 淡分隔线 | #E0E3E7 | #34363A | `outlineVariant` | 组内分隔线, 卡片内 hairline |
| 错误 | #B3261E | #FFB4AB | `error` | 错误提示, 危险动作文字 |
| 主题色 (派生) | HCT tone 40 | HCT tone 80 | `primary` | 开关, 单选, 滑条, 进度, 填充按钮, 选中描边 |
| 主题色上文字 | HCT tone 100 | HCT tone 20 | `onPrimary` | 填充按钮文字 |
| 主题色淡底 | primary @ 11% | primary @ 11% | `primaryContainer` (自定义) | 选中行底色, 芯片选中底色 |
| 涟漪 | primary @ 18% | primary @ 18% | `rippleConfiguration` | 所有可点击面 |

- 主题色派生规则不变: 原 chroma < 4 取 0, 否则 `max(chroma, 48)` 且 <= 96, 亮色 tone 40/100, 暗色 tone 80/20 (规范第 6 节); 实现复用 `AppColorPolicy`, 只增加到 `ColorScheme` 的装配.
- 用户输入的原始种子色只用于色块与 HEX 展示, 不直接上控件.
- 禁用态: 文字 `onSurface @ 38%`, 填充 `onSurface @ 12%`, 不把两者设成同一个值.

## 11. 无障碍

- 每个图标按钮的 `contentDescription` = 现有完整文案 (如 "顺时针旋转 90 度", "显示详情"); 带标签的按钮合并语义 (标签即描述, 不重复读).
- 查看器画面 `contentDescription` = "图像预览", 浮层隐藏时仍可被 TalkBack 聚焦并通过双击切换浮层 (提供 `onClick` 语义).
- 网格单元 (3.0) 读出 "文件名, 日期, 第 n 项, 共 N 项; 已选中" ; 相册单元读出 "相册名, n 张图片".
- 装饰图标 `importantForAccessibility=no` (Compose: 不设 `contentDescription`); 设置行整行一个焦点, 右箭头与开关不单独聚焦 (规范第 4 节).
- 状态行与 Snackbar 为 live region (polite); 倍率提示不读 (现有 `importantForAccessibility=no`).
- 焦点顺序: 顶栏 -> 内容 -> 底栏; 键盘 / D-pad 可达, 焦点环使用主题色 2 dp.
- 对比度: 页面文字 >= 4.5:1. 浮层按最差情况 (底图为纯白) 验证: `scrim` 55% 与 #FFFFFF 混合后的有效底色为 #737373, 白字 (`onScrim`) 对它的对比度约 4.7:1 达标, 但 70% 白 (`onScrimMuted`, 有效色约 #D5D5D5) 只有约 3.2:1 不达标; 因此元数据所在的顶栏 / 底栏在当前图像偏亮时自动提升为 `scrimStrong` (75%, 有效底色 #404040, 白字约 10.4:1, 70% 白约 6.7:1). 实现为按当前页缩略图的平均亮度选择 scrim 档位 (评审问题 R8).
- 大字号 (系统 200%) 下: 底部图标按钮标签允许 2 行, 编辑器工具标签允许省略号但 `contentDescription` 完整.

## 14. 评审问题 (已拍板, 2026-10-13)

维护者对 R1-R8 全部按建议拍板, 其中 R5 选择后者 (2.1.0 即 5 项). 结论列于 "结果" 列, 后续按结果执行.

| R2 | 编辑器一级分组用 "图标 + 文字", 二级工具也 "图标 + 文字" (比 Simple Gallery 的纯图标更占高度, 两层合计 120 dp). 还是二级只用图标 + 长按提示? | 两层都带文字, 大字号下允许省略 | 按建议 |

| R6 | 媒体网格选中态: 左上勾选 + 描边 + 缩小 0.94. 还是只用勾选 (Simple Gallery 做法)? | 三者都用 | 按建议 |

## 附录 B. 2.1.0 页面级验收清单 (供 5.2 使用)

- 首页: hero <= 120 dp; 四行操作 + 两行信息全部为 `MapleSettingsRow`; 状态行 live region; 工作中禁用.
- 设置: 规范第 2-10 节 MUST 逐条通过 (行高, 留白, 文字起点, 对话框几何, 先选后确定, 16 色与输入校验, 四个图标选项文案).
- 查看器: 浮层 scrim 档位; 元数据两行; 五按钮 `contentDescription` 与编辑按钮的入口差异化启用; 详情面板三种关闭方式; 倍率提示 900 ms; GIF FAB 仅动图; 兄弟页禁用分享 / 其他应用; 溢出三项.
- 编辑器: 四个一级分组, 二级工具与参数面板按 7.5; 工具态禁用顶栏动作; 退出确认; 撤销 / 重做 / 恢复原图.
- 转换器: 整页表单, 仅显示当前尺寸模式输入, 预估栏固定底部, 错误显示在输入框下.
- 全局: 亮 / 暗 / 大字号 200% / RTL (阿拉伯语) / 横屏 / 多窗口 六组截图存 `.bak/visual/2.1.0/`; 触控目标 >= 48 dp; TalkBack 遍历无重复焦点.
