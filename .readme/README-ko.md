### 시작하기

독립 홈 화면에서 로컬 이미지를 보고 편집하거나 변환하고 원하는 위치에 결과 저장. 공통 설정 화면에서 언어, 야간 모드, 테마 색상 및 네 가지 런처 아이콘 선택 가능.

앱 ID가 `io.github.supermonster003.autojs6.plugin.imageviewer / io.github.supermonster003.autojs6.plugin.imagetools`에서 `io.github.supermonster003.autojs6.plugin.three.maple.image`(으)로 변경됩니다. Android는 별도 앱으로 설치하며 기존 앱과 데이터를 유지할 수 있고 설정은 자동으로 이전되지 않습니다.

******

### 소개

******

Image Viewer와 Image Tools를 3-Maple Image로 통합하여 이미지 보기, 편집 및 형식 변환 제공.

보기 작업은 입력을 읽기 전용으로 사용합니다. 편집과 변환은 기본적으로 새 파일을 만들고 원본을 유지하며, `원본에 덮어쓰기`를 선택했을 때만 원본을 대체합니다 (실행 취소 가능). 독립 앱은 Android 파일 선택기를 사용합니다.

### 주요 기능

******

- 앨범 홈: 단독으로 실행하면 기기의 이미지를 앨범 그리드로 보여 주며 (표지, 이름, 개수), 승인한 폴더는 별도 그룹으로 표시됩니다. 메뉴의 `모든 폴더 내용 표시`는 평면 보기를 엽니다. 미디어 그리드는 3-6열 (메뉴 또는 핀치), 이름, 수정 날짜, 촬영 날짜, 크기, 무작위 정렬과 일별 / 월별 그룹 (그룹 제목은 위에 고정)을 지원하며 `이 앨범만`을 선택하면 현재 앨범에만 적용됩니다. 날짜 말풍선이 있는 빠른 스크롤바와 당겨서 새로고침을 제공하고, 앨범 목록은 이름, 수정 날짜, 촬영 날짜, 이미지 수로 정렬할 수 있습니다.
- 페이지 뷰어와 썸네일 바: 그리드에서 연 이미지는 앨범 전체를 좌우로 넘겨 볼 수 있고, 썸네일 바는 현재 페이지를 강조하며 탭하면 이동합니다. 돌아가면 그리드가 마지막으로 본 이미지까지 스크롤됩니다. 두 손가락으로 이미지를 회전하면 손을 뗄 때 가장 가까운 90도로 맞춰집니다 (표시만 변경, `설정` > `뷰어` > `두 손가락 회전`에서 끌 수 있음).
- 회전 저장: 뷰어가 원본에 다시 쓸 수 있으면 (예: 앨범에서 연 이미지) 회전 후 표시되는 막대에 `저장`이 나타납니다. JPEG는 방향 정보만 바꾸고 다시 압축하지 않으며 다른 정보도 유지하고, PNG와 WebP는 다시 인코딩합니다. 저장은 `원본에 덮어쓰기`와 같은 방식으로 이루어지며 실행 취소할 수 있고, `설정` > `뷰어` > `회전 후 저장 제안`에서 끌 수 있습니다.
- 슬라이드쇼와 배경화면: 뷰어 메뉴의 `슬라이드쇼`는 간격 (1-60초)마다 페이지를 넘기며, 무작위나 역순, 반복 여부, GIF 애니메이션 포함 여부, 전환 효과 (없음, 페이드, 슬라이드)를 고를 수 있습니다. 재생 중에는 버튼이 숨겨지고 화면이 계속 켜져 있으며, 탭하면 일시 정지합니다. `배경화면으로 설정`은 화면과 같은 비율의 자르기 틀로 보일 부분을 골라 홈 화면, 잠금 화면 또는 둘 다에 설정합니다.
- 취향대로: `설정` > `뷰어`에는 제스처 (한 손가락 확대/축소, 두 번 탭 확대 배율, 최대 확대 배율, 가장자리를 탭하여 넘기기, 아래로 스와이프하여 닫기, 왼쪽 스와이프로 밝기 조절)와 표시 (화면 방향, 검은 배경, 최대 밝기, 시스템 표시줄 숨기기, 화면 켜짐 유지, 미리보기 막대, 최고 화질로 표시) 항목이 있습니다. `설정` > `앨범 및 그리드`에서는 앨범과 이미지의 열 수 (세로와 가로 따로), 미리보기 모서리와 간격, 정사각형 자르기, 파일 형식 배지, 이미지 수, 앨범 이름 한 줄 표시, 움직이는 미리보기, 앨범 표지 (가장 최근, 가장 오래된 이미지 또는 앨범에서 이미지를 선택한 뒤 `더보기` > `앨범 표지로 설정`)를 정합니다.
- 확장 세부정보와 위치: `확장 세부정보`를 켜면 고른 정보 (경로, 해상도, 파일 크기, 촬영 시간과 수정 시간, 카메라, 셔터와 조리개, 초점 거리, ISO, 위치)가 뷰어 아래쪽에 글자로 표시되고 버튼과 함께 숨겨집니다. 위치는 기본적으로 숨겨지며, `위치 정보 표시`를 켰을 때만 좌표가 표시되고 지도에서 열 수 있습니다. 저장이나 변환할 때도 `위치 정보 유지`를 선택했을 때만 남습니다.
- 태블릿, 폴더블, 키보드와 스크린 리더: 창이 충분히 넓으면 홈 왼쪽에 앨범 목록, 오른쪽에 연 앨범이 표시되고, 접기, 펼치기, 회전, 화면 분할에도 연 앨범이 유지되며, 가로 화면에서는 뷰어의 미리보기 막대가 오른쪽으로 옮겨집니다. 키보드나 리모컨으로 그리드의 포커스를 옮기고 (뚜렷한 테두리 표시), 화살표 키나 Page Up / Page Down으로 넘기며, 삭제 키로 삭제합니다. TalkBack은 각 이미지의 파일 이름과 날짜를 읽어 주고, 설정 그룹은 제목으로 건너뛸 수 있습니다.
- 다중 선택과 정리: 그리드에서 이미지를 길게 누르면 선택이 시작되고, 탭하여 추가하거나 해제하며, 길게 누른 채 손가락을 움직이면 범위를 선택할 수 있습니다 (위아래 가장자리에 가까워지면 자동 스크롤). `모두 선택`과 `선택 반전`도 지원합니다. 여러 이미지를 한 번에 공유, 즐겨찾기, 이동, 복사, 삭제할 수 있고, 한 장의 이름 변경과 상세 정보 보기도 가능합니다. 이동과 복사는 앨범이나 새 앨범을 고를 수 있으며 최근 사용한 앨범이 앞에 표시됩니다. 같은 이름의 이미지가 있으면 한 번만 묻고 (둘 다 유지, 건너뛰기, 바꾸기), 여러 장일 때는 진행 상황을 표시하며 취소할 수 있습니다.
- 휴지통, 실행 취소, 즐겨찾기: 삭제한 이미지는 먼저 휴지통으로 이동하며 (Android 11 이상은 시스템 휴지통, Android 7-10은 이 앱의 휴지통으로 30일간 보관), 삭제, 이동, 이름 변경 후에는 하단 알림에서 실행 취소할 수 있습니다. 홈 오른쪽 위 메뉴의 `휴지통`에서 복원, 영구 삭제, 비우기를 할 수 있습니다. 즐겨찾기한 이미지는 앨범 목록 맨 앞의 `즐겨찾기` 앨범에 모입니다. 앨범에서 뷰어를 열면 상단 바의 하트로 현재 이미지를 즐겨찾기에 추가하고, 하단 바의 `삭제`로 삭제할 수 있습니다.
- 앨범 정리와 검색: 앨범 목록에서 앨범을 길게 누르면 여러 개를 선택할 수 있으며, `고정` (`즐겨찾기` 다음에 표시), `제외` (이 갤러리에서만 숨김, 기기의 파일은 그대로), `숨기기` (폴더에 .nomedia를 넣어 다른 갤러리에서도 보이지 않음, `모든 파일 접근` 필요), 앨범 전체 삭제 (휴지통으로, 실행 취소 가능), 앨범 이름 변경을 할 수 있습니다. `설정`의 `제외한 폴더`와 `숨긴 폴더`에서 확인하고 되돌릴 수 있습니다. 홈의 검색은 앨범 이름과 파일 이름을 찾고, 연 이미지는 검색 결과 안에서 좌우로 넘길 수 있습니다. 앨범 안의 검색은 파일 이름으로 걸러 봅니다.
- 일괄 변환: 앨범에서 이미지를 여러 장 선택하고 `더보기` > `변환`을 고르면 같은 설정 (형식, 품질, 원본 크기, 비율 또는 긴 변, 시계 방향 회전, JPEG 배경, 안전한 EXIF 유지 여부)으로 한꺼번에 변환합니다. 새 이미지는 `원래이름_converted`로 같은 앨범에 저장되며 원본을 덮어쓰지 않고, 변환 중 취소할 수 있으며, 변환하지 못한 이미지는 이유와 함께 보여 주고 다시 시도할 수 있습니다. AutoJs6 파일 관리자에서도 이미지를 여러 장 선택한 뒤 선택 막대의 `더`에서 `이미지 일괄 변환`을 고를 수 있으며 (이 버튼이 있는 AutoJs6 버전 필요), 모든 이미지가 변환된 경우에만 함께 저장합니다.
- 필요할 때만 권한 요청: 독립 홈은 처음 실행할 때 한 번만 사진 접근을 요청하고 이후에는 스스로 요청하지 않습니다. 허용하지 않아도 `이미지 선택`, `폴더 선택`, `이미지 편집`, `이미지 변환`은 시스템 선택기로 계속 사용할 수 있습니다. Android 14 이상에서는 선택한 사진만 허용 (`선택한 사진 관리`)할 수 있습니다. `설정` > `저장공간 권한`에서 다시 허용하고, 승인한 폴더 (사진 접근이 없어도 앨범으로 표시)와 선택 사항인 `모든 파일 접근`을 관리합니다. AutoJs6나 다른 앱에서 이미지를 열 때는 권한을 요청하지 않습니다.
- 앨범으로 보기: AutoJs6 파일 관리자의 폴더 메뉴에서 `앨범으로 보기`를 선택하면 해당 폴더의 이미지를 그리드로 보고 하위 폴더로 들어갈 수 있습니다. 호스트 세션을 통한 읽기 전용 접근이며 권한을 요청하거나 절대 경로를 표시하지 않습니다.
- 선택한 이미지만 열기: AutoJs6 파일 관리자의 다중 선택 모드에서 같은 폴더의 지원 이미지 최대 128개를 선택하고 `이미지 보기`를 탭합니다. 뷰어는 호스트의 선택 순서를 유지하며 이 그룹 안에서만 넘깁니다. 선택한 각 이미지는 하단 바의 `삭제`로 AutoJs6 휴지통으로 옮길 수 있으며 알림에서 실행 취소할 수 있습니다. 파일 하나를 탭해 연 이미지도 같은 방법으로 삭제할 수 있지만, 스와이프로 넘긴 같은 폴더의 다른 이미지는 삭제할 수 없습니다.
- 탭하고 탐색: 지원 이미지를 탭하면 뷰어가 바로 열립니다. 1배에서 좌우로 밀면 같은 폴더의 지원 이미지를 자연스러운 파일 이름 순서로 볼 수 있습니다.
- 자연스러운 제스처: 손가락을 중심으로 한 핀치 확대/축소 (최대 5배), 한 손가락 이동, 두 번 탭하여 화면 맞춤과 탭한 지점 중심의 2.5배 확대 전환, 시계 방향 90° 보기 회전, 화면 탭으로 컨트롤 숨기기/표시. 핀치 중과 두 번 탭한 뒤에는 현재 배율이 잠시 표시됩니다. `설정` > `뷰어`에서 이 제스처를 조정할 수 있습니다: `한 손가락 확대/축소` (기본 켜짐), `가장자리를 탭하여 넘기기`, `아래로 스와이프하여 닫기`, `왼쪽 스와이프로 밝기 조절`, 두 번 탭 확대 배율 (2.5배 또는 실제 픽셀), 최대 확대 배율 (5배, 10배 또는 실제 픽셀).
- 초대형 이미지도 선명하게 확대: JPEG, PNG 및 정적 HEIC/HEIF가 기기 텍스처 한도나 제한된 디코딩 예산을 넘으면 저해상도 미리보기를 먼저 표시하고 확대할 때 현재 보이는 영역의 고해상도 타일만 디코딩합니다. 타일 메모리는 상한이 있으며 페이지 전환이나 메모리 압박 시 즉시 해제됩니다.
- 핵심 정보를 한눈에: 오버레이 제목 바에는 파일 이름과, 여러 이미지를 열었을 때 `3 / 12` 형식의 페이지 번호가, 하단 정보 바에는 MIME 유형, 파일 크기, 디코딩된 해상도 (가로 x 세로)가 표시됩니다. Android 8.0 이상에서 디코더가 제공하는 경우 디코딩 픽셀 심도 (bpp)와 출력 색 공간도 표시됩니다.
- 상세 정보 하단 시트: `상세 정보`를 탭하면 드래그할 수 있는 시트가 열리며 파일 이름, MIME 유형, 크기, 해상도와 함께 EXIF가 있는 경우 촬영 시각, 기기, 노출 및 방향을 확인할 수 있습니다. GPS 메타데이터가 있으면 기본적으로 존재 여부만 알립니다. `설정` > `뷰어` > `위치 정보 표시`를 켜면 촬영 장소의 좌표 (십진수와 도분초)를 표시하고 `지도에서 열기`도 제공합니다. 사진은 수동 보기 회전을 적용하기 전에 EXIF 방향에 따라 자동으로 회전하거나 반전됩니다.
- 인쇄 또는 PDF 저장: 오른쪽 위 메뉴의 `인쇄 / PDF로 저장`은 EXIF 보정과 수동 보기 회전을 유지한 현재 이미지 전체를 Android 시스템 인쇄 화면으로 보냅니다. 애니메이션 GIF는 탭할 때 보이는 프레임을 사용합니다; 확대와 이동은 출력을 자르지 않으며 플러그인은 임시 이미지나 PDF 파일을 만들지 않습니다.
- 일반적인 형식 기본 지원: JPEG 계열 (JPG / JPEG / JPE / JFIF), PNG, WEBP, BMP, GIF, HEIC, HEIF, AVIF까지 총 11가지 확장자를 지원하며 GIF 애니메이션은 자동 반복 재생되고 전용 일시중지/계속 컨트롤을 제공합니다.
- 공유와 전달: 한 번의 탭으로 시스템 공유 시트를 열 수 있습니다. 오른쪽 위 메뉴의 `사본 공유`는 메타데이터 (카메라, 날짜, 위치 등)를 없앤 원본 크기 사본이나 긴 변 기준으로 줄인 사본을 공유하고, `다른 앱으로 편집`과 `다른 앱`은 이미지를 다른 앱에 넘깁니다. 앱 목록에서 이 플러그인 자신은 자동으로 제외됩니다.
- 시스템 이미지 뷰어로도 사용 가능: 독립된 Android `ACTION_VIEW` 진입점이 다른 앱의 읽기 전용 이미지 보기 요청을 안전하게 처리합니다.
- 편집기 상단 바에는 실행 취소, 다시 실행, 비교 (길게 눌러 원본 보기), 저장이 있고, 도구는 `변형`, `조정`, `필터`, `그리기`, `주석`, `텍스트`의 6개 그룹으로 나뉘며, 캔버스는 두 손가락으로 확대/축소하고 이동할 수 있습니다. 변형에는 자르기 비율 사전 설정, 90도 회전과 -45°~+45° 미세 회전, 좌우/상하 뒤집기, `크기 조정` (백분율, 긴 변 또는 직접 입력한 너비와 높이) 이 있고, 조정에는 밝기, 대비, 채도, 색온도, 노출, 색조, 밝은 영역, 어두운 영역, 선명하게, 비네팅이 있으며 조정 중 실시간 미리 보기를 지원합니다.
- 14가지 필터 (`흑백`, `세피아`, `빈티지`, `필름` 등) 는 강도를 조절할 수 있고 조정과 함께 사용할 수 있습니다. `주석`은 사각형, 타원, 화살표, 직선을 끌어서 그린 뒤 이동하고 크기를 바꿀 수 있으며, 사각형과 타원은 윤곽선 또는 채우기를 고를 수 있습니다. 캔버스를 길게 누르면 돋보기로 색을 추출하고 HEX 값을 표시합니다.
- 브러시는 펜, 형광펜, 개인정보 보호용 모자이크, 지우개를 지원하고 색상과 굵기를 기억합니다. 텍스트는 여러 줄, 크기, 색상, 윤곽선, 그림자와 드래그 배치를 지원합니다.
- 실행 취소와 다시 실행은 192 MiB 예산 안에서 최대 8개의 기록 스냅샷을 보관합니다. `원본 복원` 자체도 취소할 수 있으며 저장하지 않은 변경이 있으면 나갈 때 확인이 필요합니다.
- 저장 대화상자에서 원본 형식을 따르거나 JPEG, PNG, WebP를 선택하고 손실 품질을 조정하며 Android 11+에서 무손실 WebP를 켤 수 있습니다. 기본적으로 새 파일로 저장하고 파일 이름을 미리 보여 주며, `원본에 덮어쓰기` (형식 유지) 와 `촬영 정보 유지` (위치 정보는 기본적으로 제거되며, `위치 정보 표시`가 켜져 있으면 `위치 정보 유지`도 선택 가능) 도 선택할 수 있습니다. 덮어쓰기는 알림에서 한 번 실행 취소할 수 있습니다.
- 변환기는 JPEG / PNG / WebP, 품질 1-100 (기본 92), JPEG와 손실 WebP의 목표 파일 크기, Android 11+ 무손실 WebP, 256색 이하 이미지의 자동 인덱스 PNG 최적화를 지원합니다.
- 크기 모드는 `원본`, `백분율` (1-1000), 비율 고정이 가능한 `사용자 지정`, 기본 1920 px이며 확대하지 않는 `긴 변` 네 가지입니다. JPEG는 투명 영역을 흰색이나 검정으로 채울 수 있습니다.
- 변환 도구와 일괄 변환은 같은 양식을 사용하며, 하단에 출력 해상도, 예상 크기와 저장될 파일 이름을 실시간으로 표시하고, 변환 도구에서는 `원본에 덮어쓰기`도 선택할 수 있습니다. 안전한 EXIF 유지는 기본적으로 꺼져 있으며, 켜도 제한된 카메라 필드만 유지하고 방향을 정규화하며 포함된 미리 보기를 항상 제거합니다. GPS는 기본적으로 제거되며, `위치 정보 표시`가 켜져 있으면 `위치 정보 유지`를 선택할 수 있습니다.
- 구성 변경에도 캔버스, 대화상자 초안, 실행 취소/다시 실행 기록과 진행 중인 작업을 보존합니다. AutoJs6에서 호출하면 새 파일과 덮어쓰기 모두 호스트 세션을 통해 기록됩니다. 먼저 임시로 저장하고 다시 읽어 확인한 뒤에야 게시하므로 실패해도 쓰다 만 파일이 남지 않으며, 덮어쓰기는 8초 안에 실행 취소할 수 있습니다.
- AutoJs6 스크립트도 `gallery` 객체로 3-Maple Image 를 사용할 수 있습니다. `gallery.pick` 은 이미지 선택 화면을 열어 고른 이미지를 돌려주고, `gallery.view` 는 뷰어로 이미지를 보여 주며, `gallery.edit` 는 편집기를 열고 AutoJs6 가 결과를 저장하고, `gallery.convert` 는 화면 없이 이미지를 변환합니다. 이미지는 AutoJs6 가 열고 결과도 AutoJs6 가 기록하므로 스크립트는 자신이 접근할 수 있는 파일만 다룹니다. 이미지 선택에는 플러그인의 사진 접근 권한이 필요하며 선택 화면이 먼저 요청합니다. 이 기능에는 AutoJs6 6.8.0 호스트 빌드 5439 이상이 필요합니다.

### 설치 및 사용

******

시작하기 전에 다음 요구 사항을 확인하세요:

```text
host app: AutoJs6 (org.autojs.autojs6)
minimum host build: 5352
minimum android: 7.0 (API 24)
plugin package: io.github.supermonster003.autojs6.plugin.three.maple.image
```

설치부터 첫 이미지를 보는 것까지 4단계입니다:

1. 3-Maple Image를 단독으로 실행하면 기기의 앨범을 둘러볼 수 있습니다 (첫 실행 때 사진 접근을 한 번 요청). 오른쪽 위 메뉴에서는 여전히 로컬 이미지를 골라 보고 편집하거나 변환하고 원하는 위치에 결과를 저장할 수 있습니다.
2. AutoJs6를 열고 `플러그인 센터`에 들어가 `3-Maple Image`를 찾아 활성화합니다.
3. AutoJs6 파일 관리자에서 지원되는 아무 이미지 파일 (예: `screenshot.png`)을 찾습니다.
4. 파일을 탭하면 이미지가 전용 뷰어에서 열립니다. 폴더 메뉴에서 `앨범으로 보기`를 선택하면 해당 폴더의 이미지를 그리드로 볼 수 있습니다.

뷰어 안에서: 1배에서 좌우로 밀면 같은 폴더의 이전 또는 다음 지원 이미지로 이동합니다. 핀치 동작으로 손가락 위치를 중심으로 확대/축소하고 (1배에서 5배), 한 손가락으로 끌어 이동하며, 두 번 탭하여 화면 맞춤과 탭한 지점 중심의 2.5배 확대를 전환합니다. 핀치 중과 두 번 탭한 뒤에는 현재 배율이 잠시 표시됩니다. `회전`을 탭하면 현재 보기만 회전합니다. 활성 확대는 유지되며, 오른쪽 위 메뉴의 `확대 재설정`은 원래 방향과 화면 맞춤을 함께 복원합니다. GIF 애니메이션에는 플로팅 `애니메이션 일시중지` / `애니메이션 계속` 버튼이 표시되며 정적 이미지에는 표시되지 않습니다. 이미지를 탭하면 오버레이 막대 표시를 전환하고, `상세 정보`를 탭하면 파일 정보와 EXIF 항목이 담긴 하단 시트가 열립니다. `공유`와 `다른 앱`은 처음 연 이미지에서 사용할 수 있습니다. 세션으로만 연 이웃 페이지에는 전달 가능한 content URI가 의도적으로 없으므로 두 동작이 비활성화됩니다. 독립 실행 홈이나 다른 앱에서 연 이미지는 `편집`도 제공하여 편집기를 열고 결과를 저장할 수 있습니다. 호스트 진입과 이웃 페이지에서는 `편집`을 제공하지 않습니다. 앨범에서 연 이미지는 상단 바의 하트로 현재 이미지를 즐겨찾기에 추가하고, 하단 바의 `삭제`로 휴지통으로 옮기며 (실행 취소 가능), `다른 앱`, `이름 변경`, `이동`, `복사`는 오른쪽 위 메뉴에 있습니다. 원본에 다시 쓸 수 있으면 회전 후 표시되는 막대에 `저장`이 나타납니다. AutoJs6에서 열었을 때는 탭해서 연 이미지와 선택해서 연 각 이미지의 하단 바에 `삭제`가 표시되며 (AutoJs6 휴지통으로 이동, 실행 취소 가능), `다른 앱`은 오른쪽 위 메뉴로 옮겨집니다. 오른쪽 위 메뉴에는 `슬라이드쇼`, `배경화면으로 설정`, `사본 공유`, `다른 앱으로 편집` (현재 이미지를 다른 앱에 넘길 수 있을 때)도 있습니다. 제스처와 표시 방식은 `설정` > `뷰어`에서 조정합니다.

### 지원 형식

******

파일 관리자의 보기 동작은 다음 확장자와 정확히 일치합니다:

```text
AVIF, BMP, GIF, HEIC, HEIF, JFIF, JPE, JPEG, JPG, PNG, WEBP
```

JFIF와 JPE는 JPEG 계열의 별칭 확장자입니다. HEIC와 HEIF에는 Android 9 이상, AVIF에는 Android 12 이상이 필요합니다. 뷰어는 작은 로컬 디코더 기능 검사도 실행하며 플랫폼 디코더를 사용할 수 없을 때 구체적인 메시지를 표시합니다. 독립된 `ACTION_VIEW` 진입점은 `image/*` MIME 유형으로 요청을 받으므로 위 목록에 제한되지 않습니다. 파일 하나의 최대 크기는 8 TiB이며, 실제 디코딩 지원은 Android 플랫폼과 Glide에 따라 달라집니다.

### 자주 묻는 질문

******

**단독으로 실행하면 왜 사진 접근을 요청하나요? 거부해도 사용할 수 있나요?**

앨범 홈은 기기의 이미지 목록이 필요하므로 단독으로 처음 실행할 때 한 번 요청합니다 (Android 13 이상은 사진 및 동영상, 이전 버전은 저장공간). 이후에는 스스로 요청하지 않습니다. 접근 권한이 없어도 `이미지 선택`, `폴더 선택`, `이미지 편집`, `이미지 변환`은 시스템 선택기로 계속 사용할 수 있으며, 나중에 홈 화면 버튼이나 `설정` > `저장공간 권한`에서 허용할 수 있습니다. 시스템이 더 이상 대화상자를 보여 주지 않으면 버튼이 `앱 설정 열기`로 바뀝니다. AutoJs6나 다른 앱에서 이미지를 열 때는 어떤 권한도 요청하지 않습니다.

**Android 14 이상에서 일부 사진만 허용했더니 다른 앨범이 보이지 않아요.**

제한된 접근은 시스템 사진 선택 도구에서 고른 사진만 공개하므로 해당 사진이 있는 앨범만 표시됩니다. 홈 화면 위쪽의 `선택한 사진 관리`를 탭해 선택을 바꾸거나 `설정` > `저장공간 권한`에서 전체 접근을 다시 허용하세요.

**`모든 파일 접근`은 무엇에 쓰나요? 켜야 하나요?**

아니요. 시스템 설정 페이지를 여는 선택 사항인 고급 스위치이며, 앨범을 둘러보는 데는 사진 접근만 필요합니다. 켜면 다른 앱이 저장한 이미지를 삭제, 이동, 이름 변경할 때 묶음마다 나오던 시스템 확인이 더 이상 나오지 않습니다 (Android 12 이상에서는 `설정` > `저장공간 권한`의 `미디어 관리`만 켜도 됩니다). 앨범 숨기기 (폴더에 .nomedia 쓰기)에는 이 권한이 필요합니다. 시스템 설정에서 언제든 끌 수 있습니다.

**삭제한 이미지는 어디로 가나요? 삭제나 이동 시 시스템 확인이 나오는 이유는?**

삭제한 이미지는 먼저 휴지통으로 이동하며 홈 오른쪽 위 메뉴의 `휴지통`에서 복원할 수 있습니다. Android 11 이상은 시스템 휴지통을 사용하며 약 30일 후 시스템이 비웁니다. Android 7-10은 이 앱의 휴지통을 사용하며 30일간 보관하고, 사용 가능한 공간의 10분의 1 (최대 2 GiB)까지 사용하며, 앱을 제거하면 함께 삭제됩니다. `설정`에서 `휴지통`을 끄면 삭제 전에 확인을 거치며 실행 취소할 수 없습니다. Android 11 이상에서 다른 앱이 저장한 이미지를 변경하려면 시스템 확인이 필요하며 묶음마다 한 번만 확인합니다. `미디어 관리` (Android 12 이상) 또는 `모든 파일 접근`을 켜면 매번 확인하지 않습니다.

**`제외`와 `숨기기`는 무엇이 다른가요?**

`제외`는 이 갤러리에만 적용됩니다. 폴더의 이미지가 앨범 목록, `모든 이미지`, `즐겨찾기`, 검색에 나타나지 않으며 기기의 파일은 그대로이고, `설정` > `제외한 폴더`에서 되돌릴 수 있습니다. `숨기기`는 폴더에 .nomedia 파일을 넣으므로 시스템과 다른 갤러리 앱에서도 이미지가 보이지 않습니다 (파일은 삭제되지 않음). Android 11 이상에서는 먼저 `모든 파일 접근`이 필요하며 `설정` > `숨긴 폴더`에서 다시 표시할 수 있습니다. 둘 다 AutoJs6 파일 관리자에 표시되는 내용에는 영향을 주지 않습니다.

**파일 메뉴에 `이미지 편집`과 `이미지 변환`이 보이지 않나요?**

다음 순서로 확인하세요: AutoJs6 버전 코드가 5352 이상인지; 플러그인이 `플러그인 센터`에서 활성화되어 있는지; 파일 확장자나 MIME 유형이 지원 목록에 있는지. 셋 중 하나라도 충족하지 않으면 메뉴 동작이 나타나지 않습니다. 3.2.0부터 플러그인은 explorer-action 프로토콜 24를 선언합니다. 이를 지원하지 않는 AutoJs6에서는 플러그인의 모든 메뉴 동작 (`이미지 보기`, `앨범으로 보기` 포함) 이 표시되지 않으므로 AutoJs6를 업데이트하세요. 앨범과 단독 홈 화면에서의 편집과 변환에는 영향이 없습니다. 3.1.2 이하 버전에는 누락이 있어 세 조건을 모두 충족해도 두 항목이 나타나지 않았습니다. 3.2.0으로 업데이트하세요.

**열 때 `이미지 정보를 읽을 수 없습니다`라고 표시되거나 화면이 바로 닫히나요?**

현재 파일을 읽을 수 없는 상태입니다. 파일이 이동되거나 삭제되었거나, 공유한 앱이 접근 권한을 거둬들였거나, 내용이 확장자와 맞지 않을 (예: 손상된 파일) 수 있습니다. 현재 위치에서 다시 열거나 원래 앱에서 다시 공유하세요.

**처리 결과는 어디에 저장되나요? 원본을 덮어쓰나요?**

기본적으로 덮어쓰지 않습니다. AutoJs6에서 호출하면 결과가 새 파일 (`이름_edited` 또는 `이름_converted`) 로 원본 옆에 저장되고, 앨범이나 단독 홈 화면에서 처리하면 완료 후 저장 위치를 직접 고릅니다. 저장 대화상자나 변환 화면에서 `원본에 덮어쓰기` 를 켰을 때만 원본을 대체하며 형식은 그대로입니다. 대체한 뒤에는 알림에서 한 번 실행 취소할 수 있습니다: AutoJs6에서 호출한 경우 호스트가 이전 버전을 보관하며 8초 안에 실행 취소할 수 있고, 앨범과 홈 화면에서는 플러그인이 다음 덮어쓰기 전까지 백업 하나를 보관합니다 (256 MiB를 넘는 이미지는 실행 취소할 수 없다고 먼저 알림).

**사진의 위치 정보가 표시되거나 저장되나요?**

기본적으로는 둘 다 아닙니다: 뷰어는 이미지에 위치 정보가 있다는 것만 알려 주고, 편집, 변환, 일괄 변환, `사본 공유`로 만든 이미지에서는 위치가 제거됩니다 (`공유`는 원본 파일을 그대로 보냅니다). 필요하면 `설정` > `뷰어` > `위치 정보 표시`를 켜세요: 세부정보에 촬영 장소의 좌표가 표시되고 `지도에서 열기`를 쓸 수 있으며 (좌표는 직접 고른 지도 앱으로 전달되고, 이 플러그인에는 네트워크 권한이 없습니다), 저장과 변환 시 `위치 정보 유지` 체크박스가 나타나는데 원본에 덮어쓸 때를 포함해 기본적으로 선택되어 있지 않습니다.

**AutoJs6에서 연 이미지를 삭제할 수 있나요?**

AutoJs6에서 탭해서 연 이미지나 선택해서 연 각 이미지는 삭제할 수 있습니다. 하단 바의 `삭제`는 이미지를 AutoJs6 휴지통 (시스템 휴지통이 아님) 으로 옮기며, 알림에서 실행 취소하거나 나중에 AutoJs6의 휴지통 페이지에서 복원할 수 있습니다. 스와이프로 넘긴 같은 폴더의 다른 이미지와 `앨범으로 보기`의 이미지는 삭제할 수 없습니다. AutoJs6가 선택한 파일에만 권한을 주기 때문입니다. 이 기능에는 프로토콜 24를 지원하는 AutoJs6가 필요합니다.

**큰 이미지를 변환할 때 메모리 부족이나 픽셀 수 초과 경고가 나오나요?**

출력 크기에는 세 가지 제한이 있습니다: 한 변이 16384 px를 넘을 수 없고, 총 픽셀 수가 4천만 (40 MP)을 넘을 수 없으며, 기기 메모리 예산 안에 들어야 합니다. 원본이 제한을 넘는 경우 `크기 조정`을 `백분율`, `긴 변` 또는 `사용자 지정`으로 바꿔 출력을 줄이세요. 메모리 부족은 다른 앱을 종료하거나 해상도를 더 낮추면 대개 해결됩니다.

**편집 후 저장한 이미지의 해상도가 왜 낮아졌나요?**

편집을 부드럽고 안정적으로 유지하기 위해, 편집 픽셀 예산 (기기 메모리에 따라 최대 약 16 MP)을 넘는 이미지는 다운샘플링을 거쳐 편집기에 올라가며, 저장 결과는 편집 캔버스의 해상도와 같습니다. 픽셀을 건드리지 않고 형식이나 크기만 바꾸려면 `이미지 변환`을 사용하세요. 출력 크기에 맞춰 정밀하게 디코딩하므로 이 예산의 제한을 받지 않습니다.

**여러 이미지를 한 번에 처리하거나 결과를 다른 디렉터리에 저장할 수 있나요?**

변환은 일괄로 할 수 있습니다: 앨범에서 이미지를 여러 장 선택하고 `더보기` > `변환`을 고르면 새 이미지가 같은 앨범에 저장되고, AutoJs6 파일 관리자에서 이미지를 여러 장 선택한 뒤 `더` > `이미지 일괄 변환`을 고르면 (이 버튼이 있는 AutoJs6 버전 필요) 원본 옆에 저장됩니다. 편집은 한 번에 한 장을 처리합니다. 독립 홈 화면에서 한 장을 편집하거나 변환할 때는 저장 위치를 선택할 수 있으며 AutoJs6 호출은 원본 옆에 새 파일을 생성합니다.

### 보안

******

플러그인은 기본 거부 원칙으로 만들어졌습니다. 다음 조치는 모두 항상 켜져 있으며 끌 수 없습니다:

- 보기 작업은 입력을 읽기 전용으로 사용합니다. 편집과 변환은 기본적으로 새 파일을 만들고 원본을 유지하며, `원본에 덮어쓰기`를 선택했을 때만 원본을 대체합니다 (실행 취소 가능). 독립 앱은 Android 파일 선택기를 사용합니다.
- AutoJs6 (`이미지 보기`, `앨범으로 보기`)나 다른 앱에서 이미지를 열 때는 런타임 권한을 요청하지 않습니다. 독립 홈이 스스로 사진 접근을 요청하는 것은 최대 한 번이며, `모든 파일 접근`과 `미디어 관리`는 사용자가 시스템 설정에서 켤 때만 활성화됩니다.
- 플러그인은 네트워크 권한 (`INTERNET`)을 선언하지 않습니다. 앨범, 썸네일, 이미지 세부 정보는 기기에서 읽히며 기기 밖으로 나가지 않습니다.
- 삭제, 이동, 이름 변경, 숨기기, 원본 덮어쓰기는 사용자가 직접 선택했을 때만 실행됩니다. AutoJs6에서 열었을 때는 선택한 파일만 삭제할 수 있고 (AutoJs6 휴지통으로 이동), 다른 앱에서 연 이미지에는 삭제, 이동, 이름 변경, 숨기기가 제공되지 않습니다.

### 플러그인 인터페이스 (개발자용)

******

호스트는 다음 식별 정보로 플러그인을 검색하고 호출합니다:

```text
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: three-maple-image
engine: explorer-action
variant: default
explorer action id: view-image
protocol version: 24
MIME type: Explorer: avif/bmp/gif/heic/heif/jfif/jpe/jpeg/jpg/png/webp; ACTION_VIEW: image/*
required host build: 5352
```

현재 구현은 explorer-action 프로토콜 버전 24을 기반으로 합니다: 기본 동작 `view-image`는 단일 파일 대상, 읽기 전용 접근, `readSiblings`, `targetTrash`를 선언합니다. 호스트 세션은 바로 이웃한 파일만 노출합니다. 플러그인은 지원되고 읽을 수 있으며 심볼릭 링크가 아닌 이미지만 남기고, 자연스러운 파일 이름 순서를 적용하며, 선택 이미지 주변에 최대 128페이지의 제한된 창을 유지합니다. 선택 도구 모음 동작 `view-images`는 `readSiblings` 없이 여러 파일과 `targetTrash`를 선언하고, 같은 상위 폴더의 지원 이미지 1개에서 128개까지 받아 호스트 선택 순서를 유지하며 명시적으로 허용된 대상만 전달합니다. `targetTrash`로 뷰어는 요청 대상을 하나씩 호스트 휴지통으로 옮길 수 있으며, 이동마다 실행 취소할 수 있는 배치가 됩니다. 이웃 파일은 포함되지 않습니다. `edit-image`와 `convert-image`는 `ACCESS_MANAGE_TARGET`을 선언합니다. 새 파일은 세션을 통해 임시 저장하고 다시 읽어 확인한 뒤 게시하며, 덮어쓰기는 호스트의 대상 교체를 사용하고 `undoTargetReplacement`로 한 번 실행 취소할 수 있습니다. 파일 정보, 이동, 이름 변경은 계속 호스트 기능입니다. 플러그인이 없으면 호스트는 읽기 전용 외부 `ACTION_VIEW` 요청으로 대체합니다. 세 번째 선택 도구 모음 동작 `convert-images`는 여러 파일과 `ACCESS_CREATE_IN_PARENT`를 선언합니다. 이미지마다 원래 디렉터리에 새 파일을 만들어 다시 읽어 확인한 뒤 하나의 출력 배치로 함께 게시하며, 한 장이라도 실패하면 모두 되돌립니다.

### 리소스 구조

******

```text
.readme/lang_*.json

docs/images/screenshots/*.png
```
