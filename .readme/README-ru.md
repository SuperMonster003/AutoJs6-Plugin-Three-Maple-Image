### Начать

Отдельный главный экран позволяет открывать, редактировать и преобразовывать локальные изображения, сохраняя результат в выбранное место. Общие настройки включают язык, ночной режим, цвет темы и четыре варианта значка запуска.

Идентификатор приложения изменен с `io.github.supermonster003.autojs6.plugin.imageviewer / io.github.supermonster003.autojs6.plugin.imagetools` на `io.github.supermonster003.autojs6.plugin.three.maple.image`. Android устанавливает отдельное приложение; прежние приложения и данные можно сохранить, настройки автоматически не переносятся.

******

### Введение

******

Image Viewer и Image Tools объединены в 3-Maple Image для просмотра, редактирования и преобразования изображений.

Просмотр использует входные данные только для чтения. Редактирование и преобразование создают отдельный файл, сохраняя исходное изображение. Отдельное приложение использует системный выбор документов Android.

******

### Основные возможности

******

- Открытие точной выборки: в режиме выбора AutoJs6 отметьте до 128 поддерживаемых изображений из одной папки и нажмите `Просмотреть изображение`; средство просмотра сохраняет порядок выбора хоста и листает только внутри этой группы.
- Нажимайте и листайте: нажатие на поддерживаемое изображение сразу открывает средство просмотра; при масштабе 1x листайте влево или вправо поддерживаемые изображения из той же папки в естественном порядке имен файлов.
- Естественные жесты: масштабирование щипком с центром между пальцами (до 5x), перемещение одним пальцем, двойное нажатие для переключения между вписыванием и масштабом 2,5x с центром в точке касания, поворот вида на 90° по часовой стрелке, одиночное нажатие для скрытия или показа элементов управления. Во время щипка и кратко после двойного нажатия компактный индикатор показывает текущий масштаб.
- Четкое увеличение очень больших изображений: если статический JPEG, PNG или HEIC/HEIF превышает предел текстуры устройства либо ограниченный бюджет декодирования, сначала показывается разреженное превью, а при увеличении декодируются только видимые плитки высокого разрешения. Память плиток ограничена и освобождается при смене страницы или нехватке памяти.
- Ключевые сведения перед глазами: в наложенном заголовке отображается имя файла и, когда открыто несколько изображений, счётчик страниц вида `3 / 12`, а нижняя панель сообщает тип MIME, размер файла и декодированное разрешение (ширина x высота). В Android 8.0 и новее, если декодер предоставляет эти данные, также показываются разрядность декодированного пикселя (bpp) и выходное цветовое пространство.
- Нижняя панель сведений: нажмите `Сведения`, чтобы открыть перетаскиваемую панель с именем файла, MIME-типом, размером, разрешением и, при наличии EXIF, временем съёмки, устройством, экспозицией и ориентацией. При наличии метаданных GPS средство просмотра сообщает об этом, но скрывает координаты. До ручного поворота вида фотографии автоматически поворачиваются или отражаются согласно ориентации EXIF.
- Печать или сохранение в PDF: `Печать / сохранить PDF` в меню справа вверху отправляет полное текущее изображение в системное окно печати Android, сохраняя коррекцию EXIF и ручной поворот вида. Для анимированного GIF используется кадр, видимый в момент нажатия; масштабирование и перемещение не обрезают результат, а плагин не создаёт временных файлов изображения или PDF.
- Распространенные форматы из коробки: семейство JPEG (JPG / JPEG / JPE / JFIF), PNG, WEBP, BMP, GIF, HEIC, HEIF и AVIF, всего 11 расширений; анимированные GIF автоматически зацикливаются и имеют отдельную кнопку паузы/продолжения.
- Отправка и передача: откройте системную панель отправки одним нажатием или используйте `Открыть в` для редактирования и аннотирования; сам плагин автоматически исключается из списка приложений во избежание циклов.
- Работает как системное средство просмотра изображений: отдельная точка входа Android `ACTION_VIEW` безопасно обслуживает запросы на просмотр только для чтения от других приложений.
- Редактор предлагает предустановки обрезки, поворот на 90 градусов и точный поворот от -45° до +45°, отражение по горизонтали и вертикали, яркость, контрастность, насыщенность, цветовую температуру, кисти и стилизованный текст с живым предпросмотром.
- Типы кисти включают карандаш, маркер, мозаику для приватности и ластик с запоминанием цвета и толщины; текст поддерживает несколько строк, размер, цвет, контур, тень и размещение перетаскиванием.
- Отмена и повтор сохраняют до 8 снимков истории в пределах 192 MiB; `Восстановить оригинал` тоже можно отменить, а выход с несохраненными изменениями требует подтверждения.
- Диалог сохранения редактора может следовать исходному формату или выбрать JPEG, PNG либо WebP, настроить качество с потерями и включить WebP без потерь на Android 11+; хост публикует новый соседний файл, не перезаписывая источник.
- Конвертер поддерживает JPEG / PNG / WebP, качество 1-100 (по умолчанию 92), целевой размер для JPEG и WebP с потерями, WebP без потерь на Android 11+ и автоматическую индексированную оптимизацию PNG для изображений не более чем с 256 цветами.
- Четыре режима размера: `Исходный`, `Процент` (1-1000), `Пользовательский` с фиксацией пропорций и `Длинная сторона` (по умолчанию 1920 px, без увеличения); JPEG может заполнять прозрачность белым или черным.
- Диалог в реальном времени показывает разрешение и ожидаемый размер. Безопасное сохранение EXIF по умолчанию выключено; при включении оно оставляет ограниченные поля камеры, нормализует ориентацию и всегда удаляет GPS и встроенные эскизы.
- Изменения конфигурации сохраняют холст, черновики, историю отмены/повтора и выполняющиеся задачи; каждое действие по-прежнему использует один ввод только для чтения и одну одноразовую соседнюю транзакцию вывода, принадлежащую хосту.

### Установка и использование

******

Перед началом проверьте следующие требования:

```text
host app: AutoJs6 (org.autojs.autojs6)
minimum host build: 5276
minimum android: 7.0 (API 24)
plugin package: io.github.supermonster003.autojs6.plugin.three.maple.image
```

От установки до первого открытого изображения всего 4 шага:

1. Отдельный главный экран позволяет открывать, редактировать и преобразовывать локальные изображения, сохраняя результат в выбранное место.
2. Откройте AutoJs6, зайдите в `Центр плагинов`, найдите `Просмотр изображений` и включите его.
3. В файловом менеджере AutoJs6 найдите любой поддерживаемый файл изображения (например `screenshot.png`).
4. Нажмите на файл. Изображение откроется в специальном средстве просмотра.

Внутри средства просмотра: при масштабе 1x листайте влево или вправо к предыдущему или следующему поддерживаемому изображению из той же папки. Сводите и разводите пальцы для масштабирования вокруг точки касания (от 1x до 5x), перемещайтесь одним пальцем, а двойным нажатием переключайтесь между вписыванием в экран и масштабом 2,5x с центром в точке касания. Во время щипка и кратко после двойного нажатия показывается текущий масштаб. Нажмите `Повернуть`, чтобы повернуть только текущий вид; активный масштаб сохраняется, а `Сбросить масштаб` в меню справа вверху восстанавливает исходную ориентацию и вписывание. Для анимированных GIF показывается плавающая кнопка `Приостановить анимацию` / `Продолжить анимацию`, а для статических изображений она скрыта. Нажатие на изображение переключает видимость наложенных панелей, а `Сведения` открывает нижнюю панель со сведениями о файле и полями EXIF. `Отправить` и `Открыть в` доступны для первоначально открытого изображения; на соседних страницах сессии они отключены, поскольку у таких страниц намеренно нет передаваемого content URI.

### Поддерживаемые форматы

******

Действие просмотра в файловом менеджере точно совпадает со следующими расширениями:

```text
AVIF, BMP, GIF, HEIC, HEIF, JFIF, JPE, JPEG, JPG, PNG, WEBP
```

JFIF и JPE - расширения-псевдонимы семейства JPEG. Для HEIC и HEIF требуется Android 9 или новее, для AVIF - Android 12 или новее. Средство просмотра также запускает небольшую локальную проверку возможностей декодирования и показывает отдельное сообщение, если платформенный декодер недоступен. Отдельная точка входа `ACTION_VIEW` принимает запросы по типу MIME `image/*` и не ограничена приведенным списком. Один файл может занимать не более 8 TiB; фактическая поддержка декодирования зависит от платформы Android и Glide.

### Частые вопросы

******

**В меню файла нет пунктов `Редактировать изображение` и `Преобразовать изображение`?**

Проверьте по порядку: код версии AutoJs6 не ниже 5276; плагин включен в `Центре плагинов`; расширение файла или его MIME-тип есть в списке поддерживаемых. Если хотя бы одно условие не выполнено, действия в меню не появятся.

**При открытии появляется `Не удалось прочитать информацию об изображении` или экран сразу закрывается?**

Просмотр использует входные данные только для чтения. Редактирование и преобразование создают отдельный файл, сохраняя исходное изображение. Отдельное приложение использует системный выбор документов Android.

**Где сохраняется результат? Перезаписывается ли оригинал?**

Просмотр поддерживает выбранную группу изображений, редактирование и преобразование выполняются по одному изображению. На отдельном главном экране можно выбрать место сохранения; вызовы AutoJs6 создают новый файл рядом с исходным.

**Преобразование большого изображения сообщает о нехватке памяти или превышении числа пикселей?**

Размер вывода ограничен трижды: ни одна сторона не может превышать 16384 px, общее число пикселей не может превышать 40 миллионов (40 MP), и все должно уложиться в бюджет памяти устройства. Если источник превышает лимиты, переключите `Изменить размер` на `Процент`, `Длинная сторона` или `Пользовательский`, чтобы уменьшить вывод; при нехватке памяти обычно помогает закрыть другие приложения или еще снизить разрешение.

**Почему отредактированное изображение сохраняется с меньшим разрешением?**

Чтобы редактирование оставалось плавным и стабильным, изображения выше бюджета пикселей редактирования (до примерно 16 MP в зависимости от памяти устройства) уменьшаются перед загрузкой в редактор, и сохраненный результат соответствует холсту редактирования. Если нужно лишь сменить формат или размер, не трогая пиксели, используйте `Преобразовать изображение`: он декодирует точно под выходной размер и этому бюджету не подчиняется.

**Можно ли обработать несколько изображений сразу или сохранить результат в другой каталог?**

Просмотр поддерживает выбранную группу изображений, редактирование и преобразование выполняются по одному изображению. На отдельном главном экране можно выбрать место сохранения; вызовы AutoJs6 создают новый файл рядом с исходным.

### Безопасность

******

Плагин построен по принципу запрета по умолчанию. Все перечисленные меры всегда включены и не могут быть отключены:

- Просмотр использует входные данные только для чтения. Редактирование и преобразование создают отдельный файл, сохраняя исходное изображение. Отдельное приложение использует системный выбор документов Android.

### Интерфейс плагина (для разработчиков)

******

Хост обнаруживает и вызывает плагин по следующим идентификаторам:

```text
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: three-maple-image
engine: explorer-action
variant: default
explorer action id: view-image
protocol version: 12
MIME type: Explorer: avif/bmp/gif/heic/heif/jfif/jpe/jpeg/jpg/png/webp; ACTION_VIEW: image/*
required host build: 5276
```

Текущая реализация нацелена на версию 12 протокола explorer-action: основное действие объявляет цель в виде одного файла, доступ только для чтения и `readSiblings`. Сессия хоста показывает только непосредственных соседей; плагин оставляет поддерживаемые, читаемые изображения без символических ссылок, применяет естественный порядок имен и хранит ограниченное окно не более 128 страниц вокруг выбранного изображения. Второе действие только для чтения на панели выбора объявляет несколько файлов без `readSiblings`; оно принимает от 1 до 128 поддерживаемых изображений одного родителя, сохраняет порядок выбора хоста и передает только явно разрешенные цели. Редактирование, преобразование, сведения о файлах, удаление, перемещение и переименование остаются функциями хоста; без плагина хост переключается на внешний запрос `ACTION_VIEW` только для чтения.

### Сборка

******

```powershell
.\gradlew.bat :app:assembleDebug
```

Сборка Release:

```powershell
.\gradlew.bat :app:assembleRelease
```

Параметры сборки задаются в `version.properties`. Текущий минимальный SDK равен 24, целевой SDK равен 36.

******

### Структура ресурсов

******

```text
.readme/lang_*.json
.changelog/lang_*.json
.python/generate_markdown.py
docs/images/screenshots/*.png
app/src/main/assets/doc/CHANGELOG-*.md
app/src/main/res/values-*/strings.xml
app/src/main/res/raw-*/plugin_instruction.md
```

`strings.xml` локализует сведения о плагине и интерфейс средства просмотра, а `plugin_instruction.md` содержит инструкции, отображаемые хостом. Все файлы README и CHANGELOG генерируются из источников JSON скриптом `.python/generate_markdown.py`: чтобы изменить документацию, отредактируйте файлы `lang_*.json` в `.readme` и `.changelog` и запустите скрипт заново, не редактируя сгенерированные файлы Markdown.
